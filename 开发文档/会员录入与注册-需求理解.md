# 管理端录入会员 + 小程序注册 — 需求理解

> 2026-10-26 已按本文实现。手机号是账号。绑定码登录已去掉。

---

## 1. 一句话

会员身份是：**手机号** + **完善资料时填写的姓名** + **闸机核验通过的人脸**。微信只用来认出是谁、以及以后支付。人脸一经写入不可改。姓名和手机号可由管理端修改，修改会记入消息里的系统操作。管理端可录入会员、按门店/姓名/手机号筛选，并可编辑卡与课程。

---

## 2. 登录与再次进入

小程序打开时在后台静默识别微信（用户不用点「微信登录」）。目的只是认出微信号，以及以后微信支付。未绑定的微信先进入登录页。

| 情况 | 行为 |
| --- | --- |
| 这个微信已经绑定会员 | 直接进首页，不出现登录页 |
| 换了手机、微信没换 | 同上，不重新注册 |
| 这个微信从未绑定，手机号已是正式会员（管理端录入或以前注册过） | 用本机号或短信验证码登录。绑定当前微信，不改姓名、不重新拍脸 |
| 这个手机号还不是正式会员 | 进入信息完善页，补姓名和人脸。提交姓名时才变成正式会员 |
| 该手机号已绑在别的微信上 | 拒绝，提示「该手机号已绑定其他微信」 |

退出登录会撤销当前令牌，并把该账号的微信绑定清掉。同一微信下次打开不会自动进入，需要重新用手机号登录。要换微信，也可以在管理端对该会员点「解绑微信」。

---

## 3. 登录页与信息完善

登录页上的隐私说明是**上架用的隐私保护指引**，和《会员协议》不是同一份。正文不写在小程序里：管理端配置一个链接地址，并可复制该地址；小程序点击后直接打开这个链接。

1. 有隐私指引链接，可点开（跳到管理端配置的地址）。
2. 须勾选同意。不同意可以关掉，以未登录状态继续浏览。
3. **没勾选时，「使用本机号登录」只提示先同意，不拉起微信手机号授权。** 勾选之后，这个按钮才带微信的手机号授权。授权成功会消耗微信的手机号次数。
4. 另一条路是「其他号码登录」：填写手机号和短信验证码。
5. 已是正式会员：直接进首页。
6. 还不是正式会员：进入信息完善页。先拍正脸（仅相机），通过后再填姓名并提交。正式环境由在线闸机 `verifyPhoto` 判断照片能否录入；失败可重拍，不发会员编号。本地和开发环境用模拟检测。
7. 姓名提交成功后，一次完成：写成正式会员、写入注册时间、发放会员编号，进入首页。只拍脸、还没提交姓名的人没有会员编号。

姓名、手机号、人脸注册后不可在小程序里修改。管理端可改姓名和手机号。全站会员姓名、联系电话都读这两个字段（我的、首页、预约详情、教练拨号、管理端消息与订单）。

教练档案手机号、加盟留资电话、门店客服电话不是会员手机号，不改。

### 短信

使用**阿里云短信服务**（与服务器同在阿里云，但要单独开通签名和验证码模板）。**阿里云尚未接入。** 非本机环境点「获取验证码」会提示「短信尚未配置」。

开发阶段固定验证码（只允许本地 profile，**禁止进入正式环境**）：

| 项 | 约定 |
| --- | --- |
| 固定验证码 | `246810` |
| 生效条件 | 服务端正好是 `local`，且 `gym.sms.fixed-code` 正好是这个值 |
| 正式环境 | 不配置、不接受该固定码 |
| 频控 | 同一手机号 60 秒内不能重发，每天最多 10 次 |

手机号全库唯一。登录时若该手机号已是正式会员且尚未绑定微信，则绑定到这条会员，不新建。若已绑定别的微信，拒绝并提示。

## 4. 管理端

新增会员列表（总账号可看全部门店，门店账号只看本店）。

**筛选：** 门店、姓名、手机号。

**新建：** 姓名、手机号必填且唯一；人脸必填，走同一套闸机核验，通过才保存（本地和开发环境模拟检测，任意图片可通过）；会员卡、课程都可以多选（也可以不选）。每一张卡、每一门课程各记一笔**已支付订单**（金额按标价，进入现有财务报表）。建档时就是正式会员并分配会员编号，不生成绑定码。会员在小程序用同一手机号登录后绑定微信。

**导入旧会员：** 在录入会员页选择一台在线闸机。用 `getUserInfo` 读人员编号，再用 `getUserDetails` 读照片和到期时间，写入本系统。编号以 `DL` 开头的本机录入、黑名单、没有照片的人跳过。到期时间挂在该店已上架的一张卡上，金额为 0，不重新下发人脸。姓名和手机号闸机上没有时留空，之后在列表里补。

**隐私指引：** 管理端单独配置链接地址，提供复制。小程序只跳这个地址，不内置正文。

手机号已存在：拒绝新建，提示去会员列表找到该会员再编辑。

**编辑：** 可改姓名、手机号、补开会员卡、补开课程（同样记已支付订单）。**不可改**人脸。已绑定微信的，可以解绑，会员再用手机号在新微信上登录。姓名、手机号变更记入系统操作。

教练同样只记手机号，不生成绑定码。教练用这个手机号在小程序登录。

## 5. 本期不做

- 会员自行修改姓名、手机号、人脸
- 账号密码登录
- 短信营销（只有登录验证码）
- 阿里云真实短信（接口还没接）

## 6. 拍板记录

| 项 | 结论 |
| --- | --- |
| 账号 | 手机号。微信静默识别；已绑定直接进入 |
| 登录方式 | 勾选隐私后才能拉起本机号授权；或用其他手机号加验证码 |
| 隐私指引 | 与会员协议分开；管理端配置链接并可复制；小程序跳该链接；不同意可关闭并浏览 |
| 会员编号 | 自助注册在提交姓名、成为正式会员时发放。拍脸成功不发编号。管理端建档时发放 |
| 短信 | 阿里云短信尚未接入。开发固定码 `246810` 仅 `local`，禁止进正式环境 |
| 退出登录 | 撤销令牌并解除微信绑定 |
| 换微信 | 管理端「解绑微信」，或会员自己退出登录后再用新微信登录 |
| 卡 / 课程 | 都可多选；每张卡、每门课各一笔已支付订单 |
| 不可改 | 小程序内不能改姓名、手机号、人脸；管理端可改姓名和手机号，人脸仍不可改 |
| 手机号已存在 | 拒绝新建，到会员列表筛选后编辑卡和课程 |
| 绑定码 | 不做。`invite_code`、`invite_fail` 已从会员表删除 |

# 管理端录入会员 + 小程序注册 — 需求理解

> 2026-10-16 已按本文实现。

---

## 1. 一句话

会员身份是：**这个微信** + **注册时填写的姓名、手机号** + **闸机核验通过的人脸**。不再使用微信昵称和微信绑定手机号。人脸一经写入不可改。姓名和手机号可由管理端修改，修改会记入消息里的系统操作。管理端可录入会员、按门店/姓名/手机号筛选，并可编辑卡与课程。

---

## 2. 登录与再次进入

小程序打开时在后台静默识别微信（用户不用点「微信登录」）。目的只是认出微信号，以及以后微信支付。

| 情况 | 行为 |
| --- | --- |
| 这个微信已经绑定会员 | 直接进首页，不出现注册页 |
| 换了手机、微信没换 | 同上，不重新注册 |
| 这个微信从未绑定，门店已录入该会员 | 用手机号和一次性绑定码登录，绑定当前微信。不发短信、不重新拍脸。绑定后绑定码失效 |
| 这个微信从未注册，也没有门店录入 | 进入注册页，人脸、姓名、手机号、短信验证码 |

小程序不提供退出登录。微信一旦绑定，打开小程序就会直接进入。要换微信，由管理端重新生成绑定码，原微信随即解绑。

---

## 3. 注册页

注册页上的隐私说明是**上架用的隐私保护指引**，和《会员协议》不是同一份。正文不写在小程序里：管理端配置一个链接地址，并可复制该地址；小程序点击后直接打开这个链接。

1. 有隐私指引链接，可点开（跳到管理端配置的地址）。
2. 须勾选同意。不同意可以关掉，以未登录状态继续浏览。
3. **先拍人脸**（仅相机）。正式环境由在线闸机 `verifyPhoto` 判断照片能否录入，通过后在本页显示预览；失败不能注册。本地和开发环境用模拟检测。多台在线闸机一起分担，每台同时只测一张。
4. 填写姓名、手机号，并完成短信验证码。
5. 人脸已通过、验证码已通过、姓名和手机号已填、已同意隐私，**注册按钮才可点**。
6. 注册成功后发放会员编号，进入首页。

姓名、手机号、人脸注册后不可在小程序里修改。管理端可改姓名和手机号。现有「更换人脸」「改昵称」去掉。全站会员姓名、联系电话都读这两个字段（我的、首页、预约详情、教练拨号、管理端消息与订单）。

教练档案手机号、加盟留资电话、门店客服电话不是会员手机号，不改。

### 短信

使用**阿里云短信服务**（与服务器同在阿里云，但要单独开通签名和验证码模板，开通后才能发真实验证码）。

开发阶段固定验证码（只允许本地 profile，**禁止进入正式环境**）：

| 项 | 约定 |
| --- | --- |
| 固定验证码 | `246810` |
| 生效条件 | 仅服务端 `local` profile |
| 正式环境 | 不配置、不接受该固定码；必须走阿里云短信。发版前检查配置里没有 `246810` |

手机号全库唯一。注册时若该手机号已是会员且尚未绑定微信，则绑定到这条会员，不新建。若已绑定别的微信，拒绝并提示。

不迁移、不适配当前库里的测试数据，实现时可以清空数据库后重新启动。其他系统里的老会员不写导入程序，由员工在管理端手工录入。

## 4. 管理端

新增会员列表（总账号可看全部门店，门店账号只看本店）。

**筛选：** 门店、姓名、手机号。

**新建：** 姓名、手机号必填且唯一；人脸必填，走同一套闸机核验，通过才保存（本地和开发环境模拟检测，任意图片可通过）；会员卡、课程都可以多选（也可以不选）。每一张卡、每一门课程各记一笔**已支付订单**（金额按标价，进入现有财务报表）。同时生成 8 位绑定码。可以先没有微信，会员在小程序用手机号和绑定码绑定；绑定后绑定码作废。员工可重新生成，若已绑定则会解除原微信。

**导入旧会员：** 在录入会员页选择一台在线闸机。用 `getUserInfo` 读人员编号，再用 `getUserDetails` 读照片和到期时间，写入本系统。编号以 `DL` 开头的本机录入、黑名单、没有照片的人跳过。到期时间挂在该店已上架的一张卡上，金额为 0，不重新下发人脸。姓名和手机号闸机上没有时留空，之后在列表里补。

**隐私指引：** 管理端单独配置链接地址，提供复制。小程序只跳这个地址，不内置正文。

手机号已存在：拒绝新建，提示去会员列表找到该会员再编辑。

**编辑：** 可改姓名、手机号、补开会员卡、补开课程（同样记已支付订单）、查看或重新生成绑定码。**不可改**人脸。姓名、手机号、绑定码变更记入系统操作。绑定码本身不写入操作内容。

---

## 5. 本期不做

- 页面上的「微信登录」按钮、微信手机号授权
- 会员自行修改姓名、手机号、人脸
- 账号密码登录
- 短信营销（只有注册验证码）

---

## 6. 拍板记录

| 项 | 结论 |
| --- | --- |
| 微信登录按钮 | 不做。后台静默识别微信；已注册直接进入 |
| 隐私指引 | 与会员协议分开；管理端配置链接并可复制；小程序跳该链接；不同意可关闭并浏览 |
| 短信 | 阿里云短信；开发固定码 `246810` 仅 `local`，禁止进正式环境 |
| 注册按钮 | 人脸核验成功且验证码通过后才可点 |
| 卡 / 课程 | 都可多选；每张卡、每门课各一笔已支付订单 |
| 不可改 | 小程序内不能改姓名、手机号、人脸；管理端可改姓名和手机号，人脸仍不可改 |
| 手机号已存在 | 拒绝新建，到会员列表筛选后编辑卡和课程 |
| 数据 | 现有测试库可清空重来；其他系统老会员只靠管理端手工录入 |

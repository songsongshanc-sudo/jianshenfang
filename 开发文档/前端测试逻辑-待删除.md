# 前端测试逻辑（有正式服务器后删除）

记录小程序里为本地调试写的逻辑。有正式服务器、并准备发微信正式版时，按本文删掉或改掉。

服务端的 `local` / `dev` / `test` 配置保留，不在本文删除范围。那些 profile 继续负责本地模拟短信、模拟人脸、模拟支付、本地文件和内存令牌。

管理端没有单独的测试分支，接口地址是相对路径 `/`，不在本文范围。

## 怎么判断现在是不是测试

小程序不看服务器地址。注册页和人脸页用 `allowLocal()`：

- 微信正式版（`envVersion === "release"`）：关闭测试逻辑，打开相机，验证码留空。
- 开发版、体验版，以及网页调试（读不到版本号）：打开测试逻辑。

因此只把接口改成正式域名，开发版里仍会预填验证码、上传测试照片。

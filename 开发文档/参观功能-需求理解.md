# 参观功能

相关：[闸机对接开发设计](闸机对接开发设计.md) · [发布文档 · 业务红线](发布文档.md#业务红线上线后仍按此执行)

---

## 1. 一句话

用户付一笔**押金**购买「参观卡」，在有效期内可到**下单时选中的那一家门店**刷脸参观一次；进店后按**可参观时长**计时，按时离店则**原路退回押金**，超时则**全额扣除押金**；买了从未进店可主动退款，到期未进店系统自动退。

正式会员卡仍**不可退款**；参观押金退款走单独通路。

---

## 2. 已拍板规则

| 项 | 决定 |
| --- | --- |
| 配置范围 | 全局一份（押金/时长等），总账号可改；**通行范围是购卡时选中的门店**，不是全店通用 |
| 出店判定 | **没有独立出店接口**。采用**同店二次刷脸成功**视为离店。进店后至少隔 **60 秒** 才把下一次成功识别算出店（避免进门连刷误判） |
| 次数 | **一笔押金只能进店参观 1 次**；进店后该卡进入进行中，结束（退款或超时扣款）后作废 |
| 按时离店后退款 | 全额退，参观权结束，撤销该店因参观而下发的闸机权限（若仍有会员则保留会员权限） |
| 超时 | **全额扣押金**；扣款后仍允许刷脸出门，检测到出店或扣款超过 2 小时后再撤参观权限 |
| 有效期到期自动退 | **仅从未进店（UNUSED）** 才自动退 |
| 与正式会员 | **选中门店已有未过期会员（含跨店会员）则不可再买该店参观卡**；会员进店仍走会员逻辑 |
| 同时持有 | 同一用户同时最多一张「未使用或进行中」的参观卡 |
| 刷其他店 | **拒绝**；提示非本店参观 |
| 5 分钟提醒 | **本期仅小程序内**：首页状态条变红 + Toast |
| 购买前提 | 须已注册完成（有人脸）；未完成先引导采集 |
| 管理端 | 总账号：配置页 + 参观记录；门店账号：可看本店参观记录（只读） |

## 3. 离店怎么判定（重要说明）

厂商闸机协议里**没有单独的「出店」HTTP 接口**，只有：

- 认出人后问能不能开门（`verify_user`）
- 通行记录（`record/face`）

因此本期实现：

1. **第一次**在购卡门店刷脸成功 → 记为进店，开始计时。  
2. **同一门店再次**刷脸成功，且距离进店已满 60 秒 → 记为离店：未超时则退押金，已超时扣款则只结束行程。  
3. 小程序文案提示用户：「再次刷脸离店」。

局限：若闸机单向、用户从消防通道离开、或不刷脸离开，系统无法感知，只能靠**超时自动扣押金**兜底。若以后厂商提供进出方向或出店事件，再升级判定。

## 4. 管理端配置项

| 配置 | 说明 | 默认建议 |
| --- | --- | --- |
| 是否开启 | 关则小程序不展示购买入口 | 关 |
| 押金（分） | 支付金额 | 990（¥9.90） |
| 可参观时长（分钟） | 从进店成功起算 | 60 |
| 有效期（天） | 从支付成功起算 | 30 |
| 提醒提前量（分钟） | 首页强调提醒 | 5 |
| 说明文案 | 购卡页展示 | 内置默认文案（写明仅限选中门店） |

---

## 5. 小程序交互

首页：参观中置顶倒计时；未进店显示**门店名 + 有效期 + 退款**；开启且当前店可买时显示「到店参观」入口。

购卡页写明：押金、**仅当前选中门店**、按时退、超时扣、未进店可退。

---

## 6. 状态机

```
支付成功 → UNUSED（已绑定下单门店 store_id）
  ├─ 用户退款 / 有效期到期自动退 → REFUNDED_UNUSED / EXPIRED_REFUNDED
  └─ 在绑定门店刷脸进店 → IN_STORE
        ├─ 同店二次刷脸（间隔≥60s）且未超时 → EXITED_REFUNDED
        ├─ 超过 due_exit_at → TIMEOUT_FORFEIT
        │     └─ 再刷脸出店或超时+2h → TIMEOUT_CLOSED
        └─ 其他店刷脸 → 拒绝
```

## 7. 当前实现范围

### 已实现

- 库表 `visit_pass`（含购卡即写入的 `store_id`）+ 配置项  
- 管理端「参观卡」配置与记录  
- 小程序首页状态/入口、购卡页、未进店退款、倒计时与 5 分钟 Toast  
- 下单绑定当前门店；人脸只下发到**该店**闸机  
- 闸机：仅绑定门店可开；进店计时；同店二次识别离店并退款；超时扣款任务  

### 本期不做

- 独立出店硬件接口 / 进出方向字段  
- 微信订阅消息  
- 参观专用协议版本  
- 全店通用参观、部分扣款、多次进出

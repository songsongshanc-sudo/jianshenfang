## 小程序 AppID 与域名

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，注册小程序。见[小程序起步](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/getstart.html)。  
2. 开发管理 → 开发设置：  
   - AppID → 环境变量 `WX_MP_APPID`，以及 `code/mp/src/manifest.json` 的 `mp-weixin.appid`  
   - AppSecret → 环境变量 `WX_MP_SECRET`（只放服务器）  
3. 同一页「服务器域名」（现为未配；改成）：  
   - request / uploadFile / downloadFile：`https://api.example.com`  
   - downloadFile 另加 [OSS 公开域名](发布-OSS与高德.md)  
   - socket 合法域名：`wss://api.example.com`  
4. 接口根地址：改 `code/mp/src/api/http.ts` 的 `baseURL` 为 `https://api.example.com`，再 [打包上传](发布-打包与部署.md#小程序)。

手机号组件说明：[getPhoneNumber](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber)（约 0.03 元/次，有体验额度）。

内容安全：报修/投诉/失物走同一 AppID 的 [`msgSecCheck`](https://developers.weixin.qq.com/miniprogram/dev/server/API/sec-center/sec-check/api_msgseccheck.html) 2.0。未通过提示「内容未通过安全检查」；约两小时未打开小程序会要求重新打开后再提交。

## 微信支付

1. [成为商家](https://pay.weixin.qq.com/)，材料见[小程序接入指引](https://pay.weixin.qq.com/static/applyment_guide/applyment_detail_miniapp.shtml)。  
2. 商户号 → `WX_PAY_MCH_ID`。  
3. [关联小程序 AppID](https://pay.weixin.qq.com/doc/v3/merchant/4016328613)。  
4. [设置 APIv3 密钥](https://pay.weixin.qq.com/doc/v3/merchant/4012072195) → `WX_PAY_API_V3_KEY`（设置后不可再查看）。  
5. [申请商户 API 证书](https://pay.weixin.qq.com/doc/v3/merchant/4012072428)：  
   - 私钥文件上传步骤见 [环境变量 §私钥](发布-服务器环境变量.md#3-微信支付私钥-apiclient_keypem)  
   - 序列号 → `WX_PAY_MCH_SERIAL`  
6. 回调：`WX_PAY_NOTIFY_URL=https://api.example.com/api/mp/pay/notify`（路径固定 `/api/mp/pay/notify`）。

缺任一支付变量时接口返回「微信支付尚未配置」。全部门店是否共用一个商户号未定，先按一个商户号准备。

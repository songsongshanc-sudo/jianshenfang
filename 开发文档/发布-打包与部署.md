## 第一次上线：建议操作顺序

下面每一步都点进对应章节；不要跳过「服务器已装好」就直接 scp。

1. ECS 能 [SSH 登录](发布-服务器环境变量.md#1-ssh-与公网-ip)，安全组放行 22/80/443（见 [域名与Nginx §安全组](发布-域名与Nginx.md#4-安全组要放行端口)）。  
2. 服务器装好 [JDK / MySQL / Redis](发布-服务器环境变量.md#0-第一次上服务器要装什么)，写好 [env](发布-服务器环境变量.md#5-新建-etcgymgym-serverenv)。  
3. 本机打 **server** jar → 上传 → [systemd 启动](发布-服务器环境变量.md#7-systemd-启动后端让-java-开机自启) → 本机 `curl http://127.0.0.1:8080/api/health`。  
4. [域名解析 + SSL + Nginx](发布-域名与Nginx.md) → 浏览器打开 `https://api.example.com/api/health`。  
5. 本机打 **admin** dist → 上传到 `/var/www/gym-admin` → 打开 `https://admin.example.com`。  
6. 改小程序 `baseURL` / appid → 打包 → 开发者工具上传；微信合法域名见 [微信与支付](发布-微信与支付.md)。

## 对照表

| 端 | 场景 | 命令 / 跑法 | 产物 | 怎么用 |
| --- | --- | --- | --- | --- |
| server | 测试 | `mvn spring-boot:run` + `local`/`dev` | 无 | 本机 `http://127.0.0.1:8080` |
| server | 正式 | `mvn -DskipTests package` | `code/server/target/gym-server-0.1.0.jar` | 拷到 ECS，配合 [`/etc/gym/gym-server.env`](发布-服务器环境变量.md) 用 systemd 跑 |
| admin | 测试 | `npm run dev` | 无 | 浏览器 `http://localhost:5173` |
| admin | 正式 | `npm run build` | `code/admin/dist/` | Nginx 静态托管 + 反代 `/api` |
| 小程序 | 测试 | `npm run build:mp-weixin` | `code/mp/dist/build/mp-weixin/` | 开发者工具导入；可勾选不校验域名 |
| 小程序 | 正式 | 同上（先改 baseURL、appid） | 同上 | 开发者工具上传 → 公众平台审核 |

易混点：

- server **没有两套 jar 名**；差别是 `SPRING_PROFILES_ACTIVE`（env 里写 `prod`）。  
- admin 日常测试用 `dev`；要静态部署才 `build`。  
- 小程序测试/正式目录相同，差别在源码配置和是否提审。  
- **scp 是本机命令**；`systemctl` 是登录服务器之后的命令。

## server

### 测试（不打正式包）

工作目录必须是 `code\server`：

```powershell
cd code\server
mvn spring-boot:run "-Dspring-boot.run.profiles=local"
```

有 Docker 时先 `docker compose up -d`，再 `mvn spring-boot:run`（默认 `dev`）。详见 [调试文档](调试文档.md)。

### 正式：本机打包

在仓库根目录打开 PowerShell：

```powershell
cd code\server
mvn -DskipTests package
```

成功后应有文件：

`code\server\target\gym-server-0.1.0.jar`

这是 fat jar（依赖已打进包）。服务器只需 **JDK 17**，不必装 Maven，不必上传整个源码目录。

### 正式：上传到服务器

1. 本机确认能 SSH（把 IP 换成你的）：

```powershell
ssh root@公网IP
```

2. **服务器上**建目录后 `exit` 回本机：

```bash
sudo mkdir -p /opt/gym
exit
```

3. **本机**上传（路径按你仓库实际位置；若当前不在仓库根，先 `cd` 到含 `code` 的目录）：

```powershell
scp "code\server\target\gym-server-0.1.0.jar" root@公网IP:/opt/gym/gym-server.jar
```

上传的目标文件名固定用 `gym-server.jar`，和 [systemd 配置](发布-服务器环境变量.md#7-systemd-启动后端让-java-开机自启) 里一致，以后换版本覆盖同一个文件名即可。

4. 服务器上已写好 env、已建好 `gym-server.service` 后：

```bash
sudo systemctl restart gym-server
sudo systemctl status gym-server
sudo journalctl -u gym-server -n 50 --no-pager
```

5. 服务器上自检：

```bash
curl -sS http://127.0.0.1:8080/api/health
```

再在浏览器测：`https://api.example.com/api/health`（须已配 Nginx）。

以后只更新后端：本机重新 `package` → 再 scp 覆盖 → `sudo systemctl restart gym-server`。

## admin

### 测试

```powershell
cd code\admin
npm install
npm run dev
```

打开 `http://localhost:5173`；先起后端。高德读 `.env.local`。

### 正式：本机打包

正式包前确认：

- 高德 Key 已在构建环境准备好（`.env.production` 或构建机环境变量），见 [OSS与高德](发布-OSS与高德.md#高德地图)。改 Key 必须重新 `build`。  
- 管理端 **不用改** `baseURL`（保持 `"/"`），靠 Nginx 反代 `/api`。

```powershell
cd code\admin
npm install
npm run build
```

产物：整个目录 `code\admin\dist\`（里面有 `index.html` 和 `assets`）。  
这是纯静态文件，服务器上**不必**安装 Node，也**不要**在服务器上跑 `npm run dev`。

### 正式：上传到服务器

1. **服务器上**（若还没有）：

```bash
sudo mkdir -p /var/www/gym-admin
```

2. **本机**上传 dist 内容（注意是 `dist\*`，不要多套一层 dist 文件夹）：

```powershell
scp -r "code\admin\dist\*" root@公网IP:/var/www/gym-admin/
```

若提示权限不够，可先传到 `/tmp` 再在服务器上挪：

```powershell
scp -r "code\admin\dist\*" root@公网IP:/tmp/gym-admin-dist/
```

```bash
# 服务器上
sudo mkdir -p /var/www/gym-admin
sudo rm -rf /var/www/gym-admin/*
sudo cp -r /tmp/gym-admin-dist/* /var/www/gym-admin/
sudo ls /var/www/gym-admin
# 应能看到 index.html
```

3. Nginx 已按 [域名与Nginx §管理端](发布-域名与Nginx.md#6-写-nginx-配置详细可抄) 配好后，浏览器打开：

`https://admin.example.com`

能打开登录页，用总账号登录（上线后立刻改掉默认密码）。若页面空白或接口 404：检查 Nginx 的 `root` 与 `location /api/`。

以后只更新管理端：重新 `npm run build` → 再 scp 覆盖 → **一般不用**重启 Java；若 Nginx 有缓存极少见，`sudo systemctl reload nginx` 即可。

## 小程序

正式前先改源码（改完再打包）：

1. `code/mp/src/api/http.ts`：`baseURL` 现为 `http://127.0.0.1:8080` → `https://api.example.com`（换成你的接口域名，**不要**末尾斜杠乱加除非代码本来就要求）。  
2. `code/mp/src/manifest.json` → `mp-weixin.appid` 填正式 AppID。  
3. 微信公众平台合法域名，见 [微信与支付](发布-微信与支付.md)。

```powershell
cd code\mp
npm install
npm run build:mp-weixin
```

产物目录：`code\mp\dist\build\mp-weixin`。

1. 打开微信开发者工具 → 导入该目录。  
2. 正式上传前：详情里**不要**勾选「不校验合法域名」（那是本地调试用的）。  
3. 点 **上传**，到 [微信公众平台](https://mp.weixin.qq.com/) → 版本管理 → 提交审核 → 发布。

小程序代码**不用**传到 ECS；只要求 ECS 上的 `https://api.example.com` 已能被外网访问。

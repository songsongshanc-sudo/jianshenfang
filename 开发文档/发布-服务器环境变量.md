# 发布：服务器环境变量与装机

← 返回 [发布文档](发布文档.md)

**env 文件在哪：** 只在 ECS 上，路径固定为 **`/etc/gym/gym-server.env`**。  
不在 Git、不在 `code/server`、不是改仓库里的 `application.yml`。

yml 只声明「读哪些变量名」（如 `${MYSQL_HOST}`）；正式值写在这个 env 文件里，由 systemd 启动 jar 时注入。本机 `local`/`dev` 调试不用它。

相关：[域名与Nginx](发布-域名与Nginx.md) · [打包与部署](发布-打包与部署.md) · [微信与支付](发布-微信与支付.md)

---

## 0. 第一次上服务器要装什么

按顺序做（都在**同一台 ECS** 上）：

| 顺序 | 装什么 | 干什么 |
| --- | --- | --- |
| 1 | 能 SSH 登录 | 后面所有命令都在这台机上敲 |
| 2 | JDK 17 | 跑 `gym-server.jar` |
| 3 | MySQL 8 | 正式业务数据 |
| 4 | Redis 7 | 登录态等 |
| 5 | 写 `/etc/gym/gym-server.env` | 告诉 Java 用 `prod` 和上面的库密码 |
| 6 | 上传 jar + systemd | 开机自启后端 |
| 7 | Nginx + 域名证书 | 见 [域名与Nginx](发布-域名与Nginx.md)，可与上面交叉进行 |

下文命令以 **Ubuntu / Debian** 为例。Alibaba Cloud Linux / CentOS 把 `apt` 换成 `yum`/`dnf`，思路相同。

---

## 1. SSH 与公网 IP

**公网 IP** = 云服务器在互联网上的地址。没有它则外网 SSH、域名解析都连不上。

### 1.1 阿里云查看公网 IP

1. 打开 [ECS 控制台](https://ecs.console.aliyun.com/) → 实例与镜像 → 实例  
2. 点开你的实例 → 概览里的 **公网 IP**（或 EIP），形如 `47.xx.xx.xx`  
3. 若为「—」：绑定弹性公网 IP，或购买时勾选分配公网 IP  

### 1.2 本机用什么登录

- **Windows 10/11**：设置 → 应用 → 可选功能 → 确认已装 **OpenSSH 客户端**。然后用 **PowerShell** 或 Windows Terminal。  
- 也可在 ECS 控制台点 **远程连接**（网页终端），不必本机装 SSH。

密码或密钥：买 ECS 时设的 root 密码，或你绑定的 SSH 公钥。用户常见 `root`（部分镜像是 `ecs-user`，下面把 `root` 换成实际用户）。

### 1.3 登录命令

本机 PowerShell（IP 换成你的）：

```powershell
ssh root@47.98.xxx.xxx
```

第一次会问 `Are you sure you want to continue connecting`，输入 `yes`。再输入密码（输入时不显示字符，属正常）。

登录成功后，提示符会变成类似 `root@iZxxxxx:~#`，后面标「服务器上」的命令都在这里执行。

退出登录：`exit`。

## 2. 安装 JDK 17（服务器上）

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk
java -version
```

应看到 `openjdk version "17.x.x"`。  
记下 java 路径（写 systemd 时要用）：

```bash
which java
# 常见输出：/usr/bin/java
```

---

## 3. 安装 MySQL 8（服务器上）

```bash
sudo apt install -y mysql-server
sudo systemctl enable mysql
sudo systemctl start mysql
sudo systemctl status mysql
```

进入 MySQL（新装若 root 无密码，直接回车；若有密码按提示输入）：

```bash
sudo mysql
```

在 `mysql>` 提示符下执行（**把密码换成你自己的强密码**，并记到记事本，马上要写进 env）：

```sql
CREATE DATABASE gym DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'gym'@'localhost' IDENTIFIED BY '这里换成强密码';
GRANT ALL PRIVILEGES ON gym.* TO 'gym'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

自测：

```bash
mysql -u gym -p -h 127.0.0.1 gym
```

输入刚设的密码，能进库即可，再 `EXIT;`。

说明：库装在本机，env 里 `MYSQL_HOST=127.0.0.1` 即可，**不必**另买云数据库（见 [上线申请清单](上线申请清单.md)）。

表结构：首次用 `prod` 启动 jar 时，以你们项目实际迁移/建表方式为准（Flyway/Liquibase 或文档约定）。若启动日志报缺表，把完整报错留下来对照仓库里的 SQL/迁移脚本。

## 4. 安装 Redis（服务器上）

```bash
sudo apt install -y redis-server
sudo systemctl enable redis-server
sudo systemctl start redis-server
redis-cli ping
```

应返回 `PONG`。本机无、无密码时 env 里 `REDIS_PASSWORD=` 留空即可。

若你给 Redis 设了密码，把同一密码写入 env 的 `REDIS_PASSWORD`。

---

## 5. 新建 `/etc/gym/gym-server.env`

```bash
sudo mkdir -p /etc/gym
sudo nano /etc/gym/gym-server.env
```

写入（域名举例 `api.example.com`，库密码、密钥换成你的；微信/OSS 可先留空，配好再补）：

```bash
SPRING_PROFILES_ACTIVE=prod
SERVER_PORT=8080

MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DATABASE=gym
MYSQL_USER=gym
MYSQL_PASSWORD=这里填数据库密码

REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=

JWT_ADMIN_SECRET=至少32字节的随机串一串
JWT_MP_SECRET=至少32字节的另一串随机串

WX_MP_APPID=
WX_MP_SECRET=

WX_PAY_MCH_ID=
WX_PAY_API_V3_KEY=
WX_PAY_PRIVATE_KEY_PATH=/etc/gym/apiclient_key.pem
WX_PAY_MCH_SERIAL=
WX_PAY_NOTIFY_URL=https://api.example.com/api/mp/pay/notify

OSS_ENDPOINT=https://oss-cn-hangzhou.aliyuncs.com
OSS_BUCKET=
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_PUBLIC_BASE_URL=https://你的桶.oss-cn-hangzhou.aliyuncs.com
```

nano：`Ctrl+O` 回车保存，`Ctrl+X` 退出。然后：

```bash
sudo chmod 600 /etc/gym/gym-server.env
```

### 5.1 随机串怎么生成（JWT）

在服务器上：

```bash
openssl rand -base64 48
```

执行两次，分别贴到 `JWT_ADMIN_SECRET` 和 `JWT_MP_SECRET`。**不要**用仓库里的默认值上线。

### 5.2 变量从哪来

| 变量组 | 去哪填、去哪申请 |
| --- | --- |
| MySQL / Redis | 上文本机安装 |
| JWT | 自己生成 |
| 微信 / 支付 | [微信与支付](发布-微信与支付.md) + 下文私钥 |
| OSS | [OSS与高德](发布-OSS与高德.md) |
| 总表 | [发布文档](发布文档.md#上线配置总表) |

改完 env 必须 `sudo systemctl restart gym-server` 才生效。

## 6. 微信支付私钥 `apiclient_key.pem`

`WX_PAY_PRIVATE_KEY_PATH` 填的是**服务器文件路径**，不是把私钥正文贴进 env。

### 6.1 从商户平台拿到文件

1. [微信支付商户平台](https://pay.weixin.qq.com/) → 账户中心 → API 安全 → 申请商户 API 证书（步骤见 [微信与支付](发布-微信与支付.md#微信支付)）。  
2. 本机得到 `apiclient_key.pem`。**勿进 Git、勿发群。**  
3. 同一页记下证书序列号 → 填入 `WX_PAY_MCH_SERIAL`。

### 6.2 传到 ECS（本机 PowerShell）

先确保服务器有目录：`sudo mkdir -p /etc/gym`

```powershell
scp "C:\Users\你的用户名\Downloads\apiclient_key.pem" root@47.98.xxx.xxx:/tmp/apiclient_key.pem
```

服务器上：

```bash
sudo mv /tmp/apiclient_key.pem /etc/gym/apiclient_key.pem
sudo chmod 600 /etc/gym/apiclient_key.pem
sudo chown root:root /etc/gym/apiclient_key.pem
```

`chmod 600` = 仅所有者可读写。

确认 env 中为：

```bash
WX_PAY_PRIVATE_KEY_PATH=/etc/gym/apiclient_key.pem
```

检查：

```bash
sudo ls -l /etc/gym/apiclient_key.pem
sudo head -n 1 /etc/gym/apiclient_key.pem
```

权限应类似 `-rw-------`；首行一般为 `-----BEGIN PRIVATE KEY-----` 或 `-----BEGIN RSA PRIVATE KEY-----`（不要把全文贴到聊天）。

## 7. systemd 启动后端（让 Java 开机自启）

**systemd** = Linux 自带的「服务管家」。配好后：机器重启会自动拉起后端；你也可以用几条命令启停、看日志。

### 7.1 先放好 jar

按 [打包与部署 §server](发布-打包与部署.md#server) 在本机打出 jar，再上传：

```bash
# 服务器上
sudo mkdir -p /opt/gym
```

本机 PowerShell：

```powershell
scp "code\server\target\gym-server-0.1.0.jar" root@公网IP:/opt/gym/gym-server.jar
```

### 7.2 写服务文件

```bash
sudo nano /etc/systemd/system/gym-server.service
```

内容（`ExecStart` 里的 java 路径以 `which java` 为准）：

```ini
[Unit]
Description=gym-server
After=network.target mysql.service redis-server.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/gym
EnvironmentFile=/etc/gym/gym-server.env
ExecStart=/usr/bin/java -jar /opt/gym/gym-server.jar
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### 7.3 首次启动与常用命令

```bash
sudo systemctl daemon-reload
sudo systemctl enable gym-server
sudo systemctl start gym-server
sudo systemctl status gym-server
```

`status` 里应看到 `active (running)`。若是 `failed`，立刻看日志：

```bash
sudo journalctl -u gym-server -n 100 --no-pager
```

| 你想做的事 | 命令 |
| --- | --- |
| 改完 env 或换了 jar | `sudo systemctl restart gym-server` |
| 停止 | `sudo systemctl stop gym-server` |
| 看最近日志 | `sudo journalctl -u gym-server -n 100 --no-pager` |
| 持续盯日志 | `sudo journalctl -u gym-server -f`（Ctrl+C 退出） |

本机先测（不经 Nginx）：

```bash
curl -sS http://127.0.0.1:8080/api/health
```

通了再配/检查 [Nginx](发布-域名与Nginx.md)。外网：`https://api.example.com/api/health`。

仍报「尚未配置」或像本地模拟支付：多半变量为空、路径错，或改完没 `restart`。

## 8. 和仓库 yml 的关系

| 文件 | 要不要改 |
| --- | --- |
| `code/server/.../application.yml` | 一般不用为上线改密钥 |
| `application-prod.yml` | 一般不用改 |
| **`/etc/gym/gym-server.env`（仅服务器）** | **在这里填正式值** |

本机调试继续用 [调试文档](调试文档.md) 的 `local`/`dev`，不要把生产密码写进仓库。

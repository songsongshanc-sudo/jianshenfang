# 发布文档

正式上线怎么配、怎么打包。本地调试见 [调试文档](调试文档.md)。去哪些平台买账号/资质见 [上线申请清单](上线申请清单.md)。

**不熟悉服务器 / Nginx？** 从下面「第一次上线顺序」做起，每一步都链到带命令的专题（含名词解释）。

## 先读懂这几件事

1. **正式环境**必须是 `SPRING_PROFILES_ACTIVE=prod`。密钥写在服务器上的环境变量文件里，**不要**写进 Git 里的 yml。  
2. **举例域名**：后端 `https://api.example.com`，管理端可选 `https://admin.example.com`。换成你自己备案的域名即可。两个都是**同一个主域名**下的主机名，指向**同一台** ECS。  
3. **环境变量文件路径**（仅 ECS 上存在）：`/etc/gym/gym-server.env`。不在仓库、不在 `code/server` 里。详见 [服务器环境变量](发布-服务器环境变量.md)。  
4. **Nginx** = 服务器上的门卫：外网 HTTPS 先到它，再转给本机 Java（8080）或管理端静态文件。详解见 [域名与Nginx §名词](发布-域名与Nginx.md#0-这些词是什么先看再动手)。

## 业务红线（上线后仍按此执行）

- 购买后不能退款、不能停卡、不能改门店；退款接口固定拒绝。
- 不另买人脸云；人脸存应用机本机私有目录，不进 OSS 公开桶。
- 课时码不能开闸机。
- 好评赠卡、学生认证、美团/抖音自动核销未做；团购用管理端人工录券码。

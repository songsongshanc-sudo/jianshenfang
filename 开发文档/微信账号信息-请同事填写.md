文件找不到：在「账户中心 → API 安全」重新申请商户 API 证书。申请完会有新的序列号和新的 `apiclient_key.pem`，两个一起发我。

请再确认并告诉我：

- 产品中心 → 我的产品里，「JSAPI 支付」或小程序支付是不是已开通。
- 商户主体名称是不是和小程序主体是同一家。不是同一家请先说明，先不要关联。

没关联 AppID 的话，请在「产品中心 → AppID 账号管理」把上面的小程序 AppID 关联上，关联成功后再告诉我。

## 二、把我加为小程序开发者

请把这个微信号加为**开发者**（可以上传代码）。不要加到「体验成员」，体验成员只能打开体验版，不能上传。

微信号：____________（我来填，转发前写上）

对方要先在自己微信里能看到微信号：微信 → 我。如果那里是「未设置」，先设置微信号，再用这个号来加。昵称、手机号搜不到。

管理员按这个顺序做：

1. 用管理员微信登录 https://mp.weixin.qq.com/ ，左上角确认是这个小程序。
2. 左侧点「管理」→「成员管理」。
3. 找到「项目成员」，点右侧「添加」。
4. 用管理员微信扫页面上的二维码。
5. 搜索上面的微信号，点出来的那个人。
6. 权限只勾「开发者」，确定。
7. 被添加的人打开微信，在「公众平台安全助手」里点同意。没点同意，列表里不会生效。
8. 回到「项目成员」列表，能看到这个人，权限是「开发者」，即完成。

加好后回复我「开发者已添加」。如果提示人数已满，先不要删别人，把现有名单发我。

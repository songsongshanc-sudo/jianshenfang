# 换到可以安装 Docker 的电脑

这份说明只解决一件事：从现在这台不能装 Docker、不能装 MySQL 的电脑，换到另一台可以装 Docker Desktop 的电脑之后，怎么把项目跑起来，以及哪些东西不要拷、不要提交。

正式上传服务器仍然用 `prod`，步骤在 `开发文档/技术设计说明书.md` 第 5.1 节。新电脑上的 Docker 只是本机的 MySQL 和 Redis，不是正式环境。

---

## 1. 先记住的三件事

1. **`node_modules` 不要拷，也不要提交到 Git。** 新电脑在 `code/admin` 和 `code/mp` 里各自执行 `npm install`，依赖会按 `package-lock.json` 下载。`package-lock.json` 要留在仓库里。
2. **新电脑用 `dev`。** 先 `docker compose up -d`，再启动后端且不要加 `profiles=local`。MySQL 和 Redis 用 Docker 里的。手机号、人脸、图片上传仍和 `local` 一样，不需要微信、对象存储、人脸厂商的密钥。地图选点用高德，Key 已经在 `code/admin/.env.local` 里，克隆仓库就有。
3. **这台电脑已经录入的门店、卡种、电话在 `code/server/data` 的 H2 里。** 这个目录被 Git 忽略，也不会自动进 MySQL。新电脑用 `dev` 后是空库，只有种子总账号，门店和卡种要重新配置。

---

## 2. 不要带到新电脑的目录

| 目录 | 原因 |
| --- | --- |
| `code/admin/node_modules`、`code/mp/node_modules` | 依赖，新电脑自己 `npm install` |
| `code/server/target` | Maven 编译结果 |
| `code/mp/dist`、`code/admin/dist` | 前端构建结果，小程序到新电脑后重新编译 |
| `.tools` | 这台电脑临时放的 Maven，不进仓库 |
| `code/server/data` | 仅 `local` 的 H2 数据库和上传图片。要接着用旧数据时单独拷，不要提交 |

用压缩包或网盘搬整个工程时，把上表里的目录排除掉。已经拷过去的 `node_modules` 先删掉，再执行 `npm install`，避免两台电脑的依赖混在一起。

当前仓库的 `.gitignore` 已经包含 `**/node_modules/`、`**/dist/`、`**/target/`、`code/server/data/`、`.tools/`。Git 索引里没有跟踪 `node_modules`。如果某个远程仓库是更早、忽略规则生效前推上去的，在新电脑执行下面的命令，把它们从索引拿掉（不删本机文件夹），然后再提交一次：

```powershell
git rm -r --cached node_modules code/admin/node_modules code/mp/node_modules
```

没有这些路径时，命令会提示找不到，忽略即可。

---

## 3. 下载并配置环境

新电脑按下面的顺序装。版本和这台电脑对齐：JDK 17、Maven 3.9.9、Node.js 22。装完关掉旧的 PowerShell，新开一个窗口再做检查，否则 PATH 还是旧的。

PowerShell 不支持 `&&`。命令一条一条执行。带逗号的 Maven 参数要加引号，否则会被拆开。

### 3.1 要装的软件

| 软件 | 版本 | 下载 | 用来做什么 |
| --- | --- | --- | --- |
| Git | 当前稳定版 | https://git-scm.com/download/win | 拉取代码 |
| JDK | 17（Temurin 17 即可） | https://adoptium.net/temurin/releases/?version=17 | 后端。选 Windows x64 的 `.msi`，装 JDK，不要只装 JRE |
| Maven | 3.9.9 | https://maven.apache.org/download.cgi | 编译后端。下 Binary zip |
| Node.js | 22 LTS | https://nodejs.org/ | 管理端和小程序。安装包自带 npm。这台电脑是 Node 22.14、npm 10.9 |
| Docker Desktop | 当前稳定版 | https://docs.docker.com/desktop/setup/install/windows-install/ | 只跑 MySQL 8 和 Redis 7。不能装 Docker 的电脑跳过，后端用第 4 节的 `local` |
| 微信开发者工具 | 当前稳定版 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html | 导入并预览小程序 |

Windows 装 Docker Desktop 前要先有 WSL2。安装程序若提示缺少 WSL，用管理员 PowerShell 执行：

```powershell
wsl --install
```

装完重启电脑，再打开 Docker Desktop，等左下角引擎显示已启动。说明见 https://learn.microsoft.com/zh-cn/windows/wsl/install 。

### 3.2 配置 PATH

JDK 的 `.msi` 和 Node.js 的安装包一般会自己写入 PATH。Maven 的 zip 要自己加。

1. 把 Maven 解压到一个固定目录，例如 `C:\dev\apache-maven-3.9.9`。不要放进项目目录，也不要提交到 Git。
2. 新建系统变量 `JAVA_HOME`，值是 JDK 安装目录，例如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.x-hotspot`。指向 JDK 根目录，不要指到 `bin`。
3. 把下面两段加进系统变量 `Path`：
   - `%JAVA_HOME%\bin`
   - `C:\dev\apache-maven-3.9.9\bin`（改成实际解压路径）
4. 关掉所有已打开的终端和 Cursor，再开一个新的 PowerShell。

Maven 不用改 `settings.xml`，默认从 Maven Central 下载依赖。第一次执行 `mvn` 会比较慢。

### 3.3 装完检查

在新的 PowerShell 里执行。版本对得上再继续。

```powershell
git --version
java -version
mvn -version
node -v
npm -v
docker version
```

`java -version` 必须是 17。`mvn -version` 里的 Java 也必须是 17。不能装 Docker 的电脑，最后一条会失败，可以忽略，后端改用 `local`。

Docker 引擎起来之后，再确认这两个端口没被别的程序占用：

```powershell
docker compose version
netstat -ano | findstr ":3306 :6379 :8080 :5173"
```

`3306` 是 MySQL，`6379` 是 Redis，`8080` 是后端，`5173` 是管理端。有 LISTENING 又不是本次要启动的进程时，先停掉，避免连错库。

### 3.4 本机开发不用另配的环境变量

`local` 和 `dev` 的数据库、Redis、登录密钥、模拟支付已经写在配置文件里，新电脑不用再设这些变量。

| 项目 | `local`（没有 Docker） | `dev`（用 Docker） |
| --- | --- | --- |
| 怎么选中 | 启动参数 `-Dspring-boot.run.profiles=local` | 不传 profile。`application.yml` 默认就是 `dev` |
| 数据库 | 内嵌 H2，文件在 `code\server\data` | `127.0.0.1:3306`，库 `gym`，用户 `gym`，密码 `gym_dev` |
| Redis | 不连接 | `127.0.0.1:6379`，无密码 |
| 模拟支付 | 打开 | 打开 |
| 管理端 | `http://localhost:5173`，接口代理到 `http://127.0.0.1:8080` | 相同 |
| 小程序接口 | `code\mp\src\api\http.ts` 里写死 `http://127.0.0.1:8080` | 相同 |
| 总账号 | `admin` / `admin123`，上线前改掉 | 相同 |

微信 AppId、AppSecret、商户号、COS、腾讯地图 Key 在 `local` 和 `dev` 都不要配。配了也不会被这两套环境拿去调正式接口。这些只在服务器 `prod` 上设置，变量名见技术设计第 5.3 节。

### 3.5 微信开发者工具

1. 用微信扫码登录开发者工具。没有正式 AppID 时，导入时可以选择测试号或游客模式。仓库里 `code\mp\src\manifest.json` 的 `appid` 是空的，本机测试不用填。
2. 导入目录选 `code\mp\dist\build\mp-weixin`。这个目录要先按第 4 节或第 5 节编译出来，空仓库里默认没有。
3. 打开「详情 → 本地设置」，勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`manifest.json` 里的 `urlCheck` 已经是 `false`，勾选这一项是为了开发者工具允许访问 `http://127.0.0.1:8080`。
4. 本机登录不走微信手机号按钮。登录页在非正式版会显示「本机测试」输入框，填 11 位手机号即可。

## 4. 这台不能装 Docker 的电脑怎么启动

两台电脑都要先做完第 3 节。这一节是不能装 Docker 时的启动方式。新电脑装好 Docker 后不要用这里的后端命令，用第 5 节。

拉下代码之后：

```powershell
cd code\admin
npm install
npm run dev
```

管理端地址是 `http://localhost:5173`。总账号 `admin` / `admin123`，上线前要改掉。

另开一个终端：

```powershell
cd code\mp
npm install
npm run build:mp-weixin
```

微信开发者工具导入 `code\mp\dist\build\mp-weixin`。详情里勾选「不校验合法域名」。改了小程序源码后要重新执行 `npm run build:mp-weixin`，再在开发者工具里重新编译。不需要一直开着 `npm run dev:mp-weixin`。

再开一个终端启动后端。工作目录必须是 `code\server`，因为 H2 文件写在这个目录下的 `data`：

```powershell
cd code\server
mvn spring-boot:run "-Dspring-boot.run.profiles=local"
```

看到 `Started GymApplication` 后，接口在 `http://127.0.0.1:8080`。

从这台电脑接着用已经配好的门店时：先停掉两边的后端，把本机 `code\server\data` 整个复制到新电脑的同一位置，再用上面的 `local` 命令启动。复制时后端不能开着，否则数据库文件被占用。

注意：

- 8080 上只能有一个后端。
- `local` 的登录令牌在内存里。重启后端后，管理端和小程序都要重新登录。
- 小程序请求地址写死为 `http://127.0.0.1:8080`，管理端通过 Vite 把 `/api` 代理到同一地址。

## 5. 新电脑用 Docker 启动

管理端和小程序的安装、编译方式与第 4 节相同。后端改成下面这样。

```powershell
cd code
docker compose up -d
```

这会启动 MySQL 8（端口 3306，库 `gym`，用户 `gym`，密码 `gym_dev`）和 Redis 7（端口 6379）。时区是 `Asia/Shanghai`。

```powershell
cd code\server
mvn spring-boot:run
```

不加 `profiles=local` 时，默认就是 `dev`。Flyway 会在空库建表。种子数据只有总账号 `admin` / `admin123`、空协议和几项系统配置。

`dev` 和 `local` 的测试方式：

| 能力 | `local` 和 `dev` | 服务器 `prod` |
| --- | --- | --- |
| 数据库 | `local` 用本机 H2；`dev` 用 Docker 里的 MySQL | 服务器 MySQL |
| 登录态 | `local` 放内存，重启要重新登录；`dev` 放 Redis，重启后端不用重新登录 | Redis |
| 支付 | 点「模拟支付成功」，和正式支付走同一套会员生效 | 微信支付，需要商户号和 APIv3 密钥 |
| 手机号登录 | 测试环境填 11 位手机号 | 微信手机号，需要小程序 AppId 和 AppSecret |
| 人脸入库 | 上传一张正脸，厂商侧仍是模拟 | 等闸机接口文档，先不要配人脸密钥 |
| 图片上传 | 写到本机 `code/server/data/public` | 对象存储，腾讯云或阿里云还没定 |
| 地图选点 | 高德 JS 地图，读取 `code/admin/.env.local` | 同一把高德 Key，文件在仓库里 |

微信、对象存储、人脸厂商的密钥只在 `prod` 才需要。对象存储厂商还没定，人脸等闸机接口文档。地图选点的高德 Key 在 `code/admin/.env.local`，已经放进仓库。要配哪些、写在哪个文件，见 `开发文档/模拟与待定.md` 第四节。

## 6. 上传服务器时不要沿用本机做法

和新电脑无关、但容易一起忘：

- 进程的 `SPRING_PROFILES_ACTIVE` 必须是 `prod`，不能是 `local` 或 `dev`。
- MySQL、Redis 用服务器上的实例，环境变量 `MYSQL_*`、`REDIS_*` 必填。
- 图片改走对象存储，厂商选定前服务器不能靠 `/uploads/` 对外发图。
- 地图选点用高德，变量在 `code/admin/.env.local`。库存坐标保持 GCJ-02。
- 微信支付和真实手机号换成正式配置。人脸等闸机接口文档，先不要配厂商密钥。购买后不能退款。`local` 里的模拟支付不能出现在服务器上。

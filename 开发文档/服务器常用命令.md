# 服务器常用命令

这台测试云公网 IP：`59.110.11.215`。公司正式服务器换 IP，命令本身一样。

先分清在哪执行：

- **本机 PowerShell**：`ssh`、`scp`、`mvn`、`npm`。一条一条执行，不要用 `&&`。
- **服务器**：登录进去之后的 `systemctl`、`mysql`、`nginx`、`curl 127.0.0.1`。关掉本机窗口不会关掉服务器上的服务。

装机、写 Nginx、第一次建库见 [现在能做与域名下来再做](现在能做与域名下来再做.md)。

## 后端

服务名 `gym-server`。程序文件 `/opt/gym/gym-server.jar`，配置 `/etc/gym/gym-server.env`。只监听本机 8080，外网走 Nginx 的 80/443。

服务器上：

```bash
sudo systemctl start gym-server
sudo systemctl restart gym-server
sudo systemctl stop gym-server
sudo systemctl status gym-server
```

`status` 里应是 `active (running)`。刚启动要等几秒，Spring 打完启动日志才听端口。

看最近日志，和持续跟着刷：

```bash
sudo journalctl -u gym-server -n 100 --no-pager
sudo journalctl -u gym-server -f
```

跟着刷时用 `Ctrl+C` 停掉，服务还在跑。

本机 8080 自测，和从外网看 Nginx 是否转到后端：

```bash
curl -sS http://127.0.0.1:8080/api/health
curl -sS http://59.110.11.215/api/health
```

两处都应是 `{"code":0,"message":"ok",...}`。外网这条在域名生效后改成 `https://api.xz100w.com/api/health`。

## 换后端包

本机先打包再上传。`scp` 打到 `100%` 就是传完了，后面若出现 `IO is still pending on closed socket` 可以忽略。

```powershell
cd D:\AIProject\健身房小程序\code\server
D:\AIProject\健身房小程序\.tools\apache-maven-3.9.9\bin\mvn.cmd -DskipTests package
scp "D:\AIProject\健身房小程序\code\server\target\gym-server-0.1.0.jar" root@59.110.11.215:/opt/gym/gym-server.jar
```

服务器上：

```bash

curl -sS http://127.0.0.1:8080/api/health
```

Maven 只在 `code\server` 里执行。`code\admin` 没有 `pom.xml`。

## 改配置

服务器上编辑后必须重启后端才生效。不要把这个文件内容贴到聊天里。

```bash
sudo nano /etc/gym/gym-server.env
sudo chmod 600 /etc/gym/gym-server.env
sudo systemctl restart gym-server
```

只看有哪些变量名、不看密码：

```bash
sudo grep -E '^[A-Z_]+=' /etc/gym/gym-server.env | cut -d= -f1
```

## Nginx、管理端、H5

配置文件 `/etc/nginx/conf.d/gym.conf`。改完先测再加载，加载不会断 SSH。

```bash
sudo nginx -t
sudo systemctl reload nginx
sudo systemctl restart nginx
sudo systemctl status nginx
```

| 地址 | 目录 |
| --- | --- |
| `http://59.110.11.215` | `/var/www/gym-admin` |
| `http://59.110.11.215/h5/` | `/var/www/gym-h5` |
| `http://59.110.11.215/api/uploads/` | 转到后端，文件在 `/var/lib/gym/public`。管理端上传后应是这个地址 |

换管理端页面。本机：

```powershell
cd D:\AIProject\健身房小程序\code\admin
npm run build
scp -r "D:\AIProject\健身房小程序\code\admin\dist\*" root@59.110.11.215:/tmp/gym-admin-dist/
```

服务器上：

```bash
sudo mkdir -p /var/www/gym-admin
sudo rm -rf /var/www/gym-admin/*
sudo cp -r /tmp/gym-admin-dist/* /var/www/gym-admin/
```

换 H5。本机：

```powershell
cd D:\AIProject\健身房小程序\code\mp
npm run build:h5
scp -r "D:\AIProject\健身房小程序\code\mp\dist\build\h5\*" root@59.110.11.215:/tmp/gym-h5/
```

服务器上：

```bash
sudo mkdir -p /var/www/gym-h5
sudo rm -rf /var/www/gym-h5/*
sudo cp -r /tmp/gym-h5/* /var/www/gym-h5/
```

管理端和 H5 是静态文件，不用重启 Java。Nginx 配置没改也不用 reload。

## MySQL 和 Redis

只在服务器本机用。不要给 3306、6379 加安全组。

```bash
sudo systemctl status mysql
sudo systemctl restart mysql
sudo mysql
```

用业务账号看库：

```bash
mysql -u gym -p -h 127.0.0.1 gym
```

进去后常用：

```sql
SHOW TABLES;
EXIT;
```

Redis 只存登录态。`PONG` 表示在跑。`FLUSHALL` 会让所有人重新登录，不清会员数据。

```bash
sudo systemctl status redis-server
sudo systemctl restart redis-server
redis-cli ping
redis-cli FLUSHALL
```

## 看占用和端口

```bash
df -h
free -h
sudo du -sh /var/lib/gym/public /opt/gym /opt/gym/data/private
sudo ss -lntp | grep -E ':22|:80|:443|:8080|:3306|:6379'
```

8080、3306、6379 的地址应是 `127.0.0.1`，不要是 `0.0.0.0`。

人脸照片在 `/opt/gym/data/private/face`（后端工作目录是 `/opt/gym`）。公开图在 `/var/lib/gym/public`。

## 清空这台测试云的业务数据

会删掉会员、订单、教练、图片和人脸。账号 `gym`、环境变量、jar、Nginx 都还在。公司正式服务器不要执行。

先停后端，再删库和文件，最后启动。Flyway 会按空库重建表，总账号回到初始的 `admin` / `admin123`，登录后立刻改掉。

```bash
sudo systemctl stop gym-server
sudo mysql <<'EOF'
DROP DATABASE IF EXISTS gym;
CREATE DATABASE gym DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
GRANT ALL PRIVILEGES ON gym.* TO 'gym'@'localhost';
FLUSH PRIVILEGES;
EOF
sudo rm -rf /var/lib/gym/public/*
sudo mkdir -p /var/lib/gym/public
sudo rm -rf /opt/gym/data/private
redis-cli FLUSHALL
sudo systemctl start gym-server
curl -sS http://127.0.0.1:8080/api/health
```

`curl` 若提示连接被拒绝，等十几秒再执行一次。启动失败看 `sudo journalctl -u gym-server -n 100 --no-pager`。

## 开机自启

装机时已经 enable 过。想确认：

```bash
sudo systemctl is-enabled gym-server mysql redis-server nginx
```

四行都应是 `enabled`。重启整台云服务器：

```bash
sudo reboot
```

SSH 会断开。过一两分钟再 `ssh root@59.110.11.215`，然后看 `systemctl status gym-server`。

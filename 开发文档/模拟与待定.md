# 模拟功能与待定事项

记录到 2026-10-09。后面补真实能力或给出确定规则时，按本文件逐项处理。

代码里的模拟都走和正式环境同一个接口。页面上没有另写一条“假装成功”的分支。`prod` 配置缺少密钥时会直接拒绝，不会悄悄当成成功。

## 已确定

1. **不支持退款。** 买了不能退，也不能停卡、不能改门店。管理端没有退款入口，退款接口一律返回「购买后不能退款」，不会改订单和会员时间。
2. **图片用对象存储，厂商还没定。** 腾讯云、阿里云都可以，等选定后再接。现在不要按某一家去配密钥。
3. **人脸和闸机识人先待定。** 等闸机接口文档后再接。注册侧按上传一张正脸照片处理，不从相册选。

## 一、已经在用的模拟

这些在本机 `local`、换设备后的 `dev`、单元测试都走模拟。只有 `prod` 切到正式实现，而且正式实现目前多数仍是“未配置就拒绝”。

| 能力 | 现在怎么做 | 正式环境要补 |
| --- | --- | --- |
| 微信手机号登录 | `local` / `dev` / 测试：手机号凭证写成 `1` 开头的 11 位数字，就当成这个手机号。`wx.login` 的 code 只换成测试 openid，不算登录成功 | 接微信 `getPhoneNumber`。`prod` 现在会返回「微信小程序尚未配置」 |
| 人脸照片 | 注册必须上传一张正脸。照片小于 32 字节会要求重拍。本机只记下字节数和对象键，不保存可查看的原图。厂商编号是模拟的 `mock-{用户}-{随机}`，用来让注册能走完 | 等闸机接口文档。文档到来之前不接人脸厂商，也不配人脸密钥。预期仍是只上传这一张照片 |
| 图片上传 | Banner、封面、到店指引写到本机 `code/server/data/public`，返回 `http://127.0.0.1:8080/uploads/...` | 对象存储，腾讯云或阿里云等选定后再接。`prod` 现在会拒绝上传 |
| 地图选点 | 管理端用高德 JS 地图选点，坐标是 GCJ-02。Key 放在 `code/admin/.env.local`，随仓库一起保存。没配 Key 时地图打不开，可以手填经纬度 | 上线用同一把 Key。服务端旧的腾讯逆地理接口还在，选点已经不走它 |
| 支付 | `local`、`dev`、单元测试打开「模拟支付成功」，和以后的微信支付回调走同一套履约。购卡会写会员，购课只加课时。没有退款 | `prod` 关闭模拟支付。现在会返回「微信支付尚未配置」。还没有微信下单和回调验签 |
| 登录态 | 本机和单元测试的令牌在内存里，重启后端后要重新登录。`dev` 和 `prod` 用 Redis，重启后登录还在 | 上线用 Redis |
| 数据库 | 本机和单元测试用 H2。`dev` 用 Docker 里的 MySQL | 上线用 MySQL。H2 里的门店和卡种不会自动迁过去 |
| 关单 | 超时关单会调用支付网关的关单。模拟支付可以关。`prod` 未配置时关单会失败，过期订单可能关不掉 | 接上微信关单后再启用定时关单 |

## 二、后续阶段里仍是模拟或占位的

| 能力 | 现在怎么做 | 正式环境要补 |
| --- | --- | --- |
| 闸机验权 | 管理端「模拟验码」用设备密钥做 HMAC-SHA256。本系统不识别人脸，只判断该不该开门。签名串是 `设备编号 + 换行 + 时间戳 + 换行 + 随机串 + 换行 + 原始请求体` | 等闸机接口文档。文档如果和现在的验权格式不一致，再改适配，不先绑死厂商 SDK |
| 防重放和 15 秒防抖 | 本机和单元测试放内存。`dev` / `prod` 放 Redis。同一人、同一闸机、15 秒内第二次成功开门不再记第二条成功流水，仍然返回开门 | 多实例时必须用 Redis。本机重启会清空防抖 |
| 在线人数 | 按配置的分钟数（默认 90）统计该店成功进店的去重人数。有效会员看到数字，其他人看到「开通会员后查看」。总账号工作台是各店人数相加，同一个人若在两店都进过会算两次 | 窗口分钟数可以改配置。统计口径如果要改成全店去重，需要另定 |
| 团购核销 | 券码只存 SHA-256。小程序提交平台和券码，规则匹配后走和购卡相同的会员区间，来源是 `GROUPON`。没有规则或券已使用会失败，不会开通会员。同一用户一分钟最多提交 5 次 | 美团、抖音的自动核销接口还没接。现在要先在管理端录入券码和对应卡种 |
| 内容安全 | 报修、投诉、失物文字里如果包含「违禁」会拒绝。其他文字直接通过 | 接微信 `msgSecCheck`。`prod` 未配置时这些提交会返回「内容安全尚未配置」 |
| 器械视频 | 管理端填写视频链接，小程序用这个链接播放。没有做 200MB 直传 | 和图片用同一家对象存储，厂商选定后再做直传，单文件不超过 200MB |
| 课时码 | 出示后 60 秒内有效，存在本机内存。教练核销看的是教练表里的手机号是否等于当前登录会员的手机号。闸机验码遇到 `lesson:` 开头一律不开门 | 多实例要改成 Redis。教练是不是单独登录，见待定 |
| 好评赠卡 | 美团、抖音都是空列表 | 赠送天数确定后再开通或延长会员。现在不会发会员 |
| 学生认证 | 只有「未认证」状态 | 认证方式和折扣确定前，不改任何卡价 |
| 站内消息 | 总账号按用户编号发消息，会员可标已读 | 没有模板、推送和运营规则 |
| 更换人脸 | 已注册会员可以再上传一张照片，成功后换成新的模拟编号 | 等闸机接口文档。在那之前，更换也只是再上传一张照片 |

2. 好评赠卡送几天，还没定。页面只说明不会赠送会员。
3. 学生认证通过后打几折、哪些卡参加，还没定。入口只显示未认证。
4. 设置里的隐私政策、注销账号还没定。现在只有已发布的会员协议和退出登录。
5. 训练计划和锻炼记录按原计划不做空页面。
6. 团购是先由总账号把券码配成规则，会员提交后立即核销。平台侧自动核销接口以后再接。
7. 全部门店是否共用一个微信商户号，还没定。门店上的商户号字段仍为空。
8. 教练目前没有单独登录。核销课时的人，必须是已注册会员，且手机号和教练资料里的手机号一致。如果以后要单独的教练账号，要改这里。
9. 会员协议、隐私政策、注销的正文还没定。购买前仍必须有一份已发布的会员协议。

11. 未匹配到会员的识别结果不写进店记录，因为进店记录要求必须有用户。如果以后要记下「陌生人」，需要允许用户编号为空。是否要记，等闸机接口文档。
12. 违规扣天数会写入 `membership_day_adjust`，这是总账号处理违规，不是用户退款。
13. 到店指引的排序用上移、下移，保存时按顺序写入。没有单独的拖拽组件。
14. 对象存储选腾讯云还是阿里云，选定前不增加云厂商密钥。

## 四、发布版本要配置的密钥

密钥放在**服务器进程的环境变量**里，不写进 Git，也不要配在本机 `local` / `dev`。Spring 按下面的文件读取。改完后进程的 `SPRING_PROFILES_ACTIVE` 必须是 `prod`。

### 现在就会读取，发布时必须改

| 变量 | 作用 | 代码位置 |
| --- | --- | --- |
| `SPRING_PROFILES_ACTIVE` | 必须是 `prod` | `code/server/src/main/resources/application.yml` 的 `spring.profiles.active` |
| `MYSQL_HOST` | MySQL 地址 | `application-prod.yml` |
| `MYSQL_PORT` | 端口，默认 3306 | 同上 |
| `MYSQL_DATABASE` | 库名 | 同上 |
| `MYSQL_USER` | 账号 | 同上 |
| `MYSQL_PASSWORD` | 密码 | 同上 |
| `REDIS_HOST` | Redis 地址 | 同上 |
| `REDIS_PORT` | 端口，默认 6379 | 同上 |
| `REDIS_PASSWORD` | 密码，没有密码就留空 | 同上 |
| `JWT_ADMIN_SECRET` | 管理端登录令牌密钥，至少 32 字节。不配会用仓库里的开发默认值，不能上线 | `application.yml` 的 `gym.jwt.admin-secret` |
| `JWT_MP_SECRET` | 小程序登录令牌密钥，至少 32 字节，和管理端不是同一串 | `application.yml` 的 `gym.jwt.mp-secret` |

可选：`SERVER_PORT` 改服务端口，默认 8080，也在 `application.yml`。`PUBLIC_FILE_BASE_URL` 只给本机图片链接用，正式环境改对象存储后不再靠它对外发图。

高德地图 Key 不配在后端。写在 `code/admin/.env.local`，这个文件进 Git，`npm run dev` 和 `npm run build` 都会读它，打包时写进页面：

```
VITE_AMAP_KEY=高德 Web端(JS API) Key
VITE_AMAP_SECURITY_JS_CODE=高德安全密钥
```

`npm run dev` 是 development 模式，不会读 `.env.production.local`。开发和上线用同一把 Key 时，只保留 `.env.local`。只有正式环境要换另一把 Key 时，才在打包机器上再写 `.env.production.local`，它只在 `npm run build` 时生效，并盖过 `.env.local`。

在 `code/admin` 执行 `npm run build`，把生成的 `dist` 部署到管理端网站。已经打好的包不会再读服务器上的环境变量，改 Key 后要重新打包。高德控制台里还要把正式管理端域名加到这把 Key 的域名白名单。安全密钥会出现在浏览器里，这是高德 JS 地图的用法。

### 设计里预留了名字，当前代码还没读取

下面这些不在微信开发者工具里申请，也不在开发者工具里填写。健身房要收会员费，并用微信手机号登录，小程序按**企业或个体工商户**注册，再完成微信认证。个人主体不能使用手机号快速验证，也不能按小程序支付接入。

值齐了之后发给开发即可。`AppSecret`、APIv3 密钥和私钥文件只写到跑后端的服务器环境变量里，和 `MYSQL_PASSWORD` 同一处，不进 Git。当前代码还没读取这些变量，发过来之后还要再接微信接口，接上之前 `prod` 仍会拒绝。

#### 小程序 AppID 和 AppSecret

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，右上角「立即注册」，账号类型选小程序。注册说明见[小程序起步](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/getstart.html)。
2. 用管理员微信扫码登录。左侧「管理 → 开发管理 → 开发设置」。
3. 页面上的 AppID 就是 `WX_MP_APPID`。AppSecret 点「生成」，管理员扫码后只显示一次，抄下来作为 `WX_MP_SECRET`。忘了只能重置。查看和重置说明见[官方文档](https://developers.weixin.qq.com/doc/oplatform/developers/dev/appid)。
4. 同一个 AppID 还要填进 `code/mp/src/manifest.json` 的 `mp-weixin.appid`。

手机号快速验证只对非个人主体、且已完成认证的小程序开放。每次调用成功约 0.03 元，每个小程序有 1000 次体验额度。说明见[手机号快速验证组件](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber)。

#### 微信支付商户号、密钥和证书

1. 电脑打开 [微信支付商户平台](https://pay.weixin.qq.com/) 点「成为商家」，或在微信里打开「微信支付商家助手」小程序再点「成为商家」。小程序收款的材料清单见[小程序接入指引](https://pay.weixin.qq.com/static/applyment_guide/applyment_detail_miniapp.shtml)。
2. 主体选个体工商户或企业。准备营业执照、法人身份证、结算银行账户。审核大约 1 到 3 个工作日。通过后，邮件和「微信支付商家助手」里会有商户号，这就是 `WX_PAY_MCH_ID`。
3. 把小程序 AppID 绑到这个商户号：商户平台「产品中心 → APPID授权管理 → 关联 AppID」。小程序和商户号主体一致时可以直接提交。步骤见[绑定 AppID](https://pay.weixin.qq.com/doc/v3/merchant/4016328613)。
4. 设置 APIv3 密钥：商户平台「账户中心 → 账户设置 → API安全 → 设置 APIv3 密钥」。自己填 32 位数字和大小写字母，这就是 `WX_PAY_API_V3_KEY`。设置成功后不能再查看，只能重新设置。说明见[配置 APIv3 密钥](https://pay.weixin.qq.com/doc/v3/merchant/4012072195)。
5. 申请 API 证书：同一页的「商户API证书」。按页面下载证书工具，在自己电脑上生成证书。文件夹里的 `apiclient_key.pem` 放到服务器上，路径写入 `WX_PAY_PRIVATE_KEY_PATH`。证书序列号写入 `WX_PAY_MCH_SERIAL`。说明见[申请商户 API 证书](https://pay.weixin.qq.com/doc/v3/merchant/4012072428)。

`WX_PAY_NOTIFY_URL` 不用向微信申请。服务器有了外网 HTTPS 域名之后，我们自己定一个回调地址，下单时由服务器告诉微信。

小程序访问后端的域名，在公众平台「开发管理 → 开发设置 → 服务器域名」里填写。开发者工具只用来导入、预览和上传代码。本机调试可以勾选不校验合法域名。

对象存储先不要配 `COS_*` 或阿里云的 AccessKey。厂商没选定，代码里也没有读取这些变量。`prod` 上传图片会提示服务商还没选定。

人脸厂商密钥先不要配。等闸机接口文档后再决定变量名和配置位置。

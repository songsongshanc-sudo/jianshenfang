# 正式服务器配置

拿到一台新的云服务器和一个已备案域名之后，按下面顺序做。做完，服务端、管理端、小程序、闸机能连上这台机器。

文中的 `example.com`、公网 IP、密码都换成你自己的。测试云 `59.110.11.215` 的日常操作不要看本文，看 [调试文档](调试文档.md)。闸机屏上的字段见 [闸机屏端配置](闸机屏端配置.md)。

命令分两处：

- **本机 PowerShell**：`ssh`、`scp`、`mvn`、`npm`。一条一条执行，不要用 `&&`。
- **服务器**：SSH 登录之后的 `apt`、`mysql`、`systemctl`。

Maven 只用在 `code\server`。本机路径：

`D:\AIProject\健身房小程序\.tools\apache-maven-3.9.9\bin\mvn.cmd`

以下安装命令按 Ubuntu / Debian。别的系统把 `apt` 换成该系统的包管理器，包名以 JDK 17、MySQL 8、Redis、Nginx 为准。

---

## 0. 先办完这些再配机器

主体用企业或个体工商户。域名、云服务器、备案、证书放在同一家云。

| 顺序 | 办什么 | 办完拿到 |
| --- | --- | --- |
| 1 | 营业执照 | 小程序、支付、备案都要用 |
| 2 | 一台云服务器 + 一个主域名 | 公网 IP。主机名用 `api.example.com`，管理端用 `admin.example.com`，都解析到这台 |
| 3 | 网站 ICP 备案 + SSL 证书 | 小程序只能访问已备案的 HTTPS |
| 4 | 微信小程序注册、认证、备案、类目 | AppID、AppSecret。个人主体不能用手机号快速验证 |
| 5 | 微信支付商户号，关联这个小程序 | 商户号、APIv3 密钥、API 证书私钥和序列号 |
| 6 | 高德 Web 端（JS API）Key | 只给管理端选门店坐标。小程序地图用微信自带地图 |
| 7 | 现场闸机，对接方式选开发者 | 设备 SN。不买人脸云，不买对象存储 |

不用另买：云数据库、对象存储、短信通道（登录用微信手机号组件；短信登录尚未接入）、美团/抖音开放平台（团购在管理端手工录券码）。

向同事要密钥时只要这些，不要 App 名称、主体、原始 ID：

| 项 | 放到哪里 |
| --- | --- |
| 小程序 AppID | 服务器 `WX_MP_APPID`，以及 `code/mp/src/manifest.json` 的 `mp-weixin.appid` |
| 小程序 AppSecret | 只放服务器 `WX_MP_SECRET`。32 位，不要把同一串贴两遍 |
| 商户号、APIv3 密钥、证书序列号 | 服务器环境变量 |
| 商户 API 私钥文件 | 服务器 `/etc/gym/apiclient_key.pem`，不要贴进环境变量，不要进 Git |

## 1. 登录服务器，装 JDK、MySQL、Redis、Nginx

安全组只放行 22、80、443。不要对公网开放 8080、3306、6379。

```powershell
ssh root@公网IP
```

服务器上：

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk mysql-server redis-server nginx
java -version
which java
sudo systemctl enable mysql redis-server nginx
sudo systemctl start mysql redis-server nginx
redis-cli ping
```

`java -version` 应是 17。`which java` 常见是 `/usr/bin/java`。`redis-cli ping` 应是 `PONG`。

建库（密码换成强密码，下一步要写入环境变量）：

```bash
sudo mysql
```

```sql
CREATE DATABASE gym DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'gym'@'localhost' IDENTIFIED BY '这里换成强密码';
GRANT ALL PRIVILEGES ON gym.* TO 'gym'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

```bash
mysql -u gym -p -h 127.0.0.1 gym
```

能进去再 `EXIT;`。表不用手建。第一次用 `prod` 启动 jar 时，Flyway 会自己建表。

## 2. 域名和证书

DNS：`api.example.com`、`admin.example.com` 两条 A 记录都指向这台公网 IP。

证书在云厂商申请，下载 **Nginx** 格式，得到 pem 和 key。本机上传前，服务器上先：

```bash
sudo mkdir -p /etc/nginx/ssl
sudo chmod 700 /etc/nginx/ssl
```

本机（文件名换成你下载的）：

```powershell
scp "C:\Users\你的用户名\Downloads\证书目录\xxx.pem" root@公网IP:/etc/nginx/ssl/api.example.com.pem
scp "C:\Users\你的用户名\Downloads\证书目录\xxx.key" root@公网IP:/etc/nginx/ssl/api.example.com.key
```

管理端若是另一张证书，同样放到 `/etc/nginx/ssl/admin.example.com.pem` 和 `.key`。通配符证书可以两个站点共用同一对文件。

## 3. 环境变量和支付私钥

```bash
sudo mkdir -p /etc/gym /var/lib/gym/public /opt/gym
sudo nano /etc/gym/gym-server.env
```

内容（两串 JWT 用下面的 `openssl` 各生成一次，不要用仓库默认值）：

```bash
SPRING_PROFILES_ACTIVE=prod
SERVER_PORT=8080

MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DATABASE=gym
MYSQL_USER=gym
MYSQL_PASSWORD=这里填数据库密码

REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=

JWT_ADMIN_SECRET=至少32字节的随机串
JWT_MP_SECRET=另一串随机串

WX_MP_APPID=
WX_MP_SECRET=

WX_PAY_MCH_ID=
WX_PAY_API_V3_KEY=
WX_PAY_PRIVATE_KEY_PATH=/etc/gym/apiclient_key.pem
WX_PAY_MCH_SERIAL=
WX_PAY_NOTIFY_URL=https://api.example.com/api/mp/pay/notify

PUBLIC_FILE_DIR=/var/lib/gym/public
PUBLIC_FILE_BASE_URL=https://api.example.com
```

生成 JWT：

```bash
openssl rand -base64 48
```

执行两次，分别填两个 `JWT_`。然后：

```bash
sudo chmod 600 /etc/gym/gym-server.env
```

微信支付：商户平台 → 账户中心 → API 安全。设置 APIv3 密钥（设完不能再查看），申请 API 证书，本机得到 `apiclient_key.pem`，同一页记下证书序列号填进 `WX_PAY_MCH_SERIAL`。

本机上传私钥：

```powershell
scp "C:\Users\你的用户名\Downloads\apiclient_key.pem" root@公网IP:/tmp/apiclient_key.pem
```

服务器上：

```bash
sudo mv /tmp/apiclient_key.pem /etc/gym/apiclient_key.pem
sudo chmod 600 /etc/gym/apiclient_key.pem
sudo chown root:root /etc/gym/apiclient_key.pem
```

`sudo head -n 1 /etc/gym/apiclient_key.pem` 应是 `-----BEGIN PRIVATE KEY-----` 或 `-----BEGIN RSA PRIVATE KEY-----`。不要把全文贴出来。

微信还没批下来时，`WX_MP_*` 和 `WX_PAY_*` 可以先留空。空着时登录会提示小程序未配置，支付会提示尚未配置。补上之后执行 `sudo systemctl restart gym-server`。

改任何环境变量都要重启后端才生效。

## 4. Nginx

```bash
sudo nano /etc/nginx/conf.d/gym.conf
```

整段贴入，替换域名和证书路径：

```nginx
server {
    listen 443 ssl;
    server_name api.example.com;

    ssl_certificate     /etc/nginx/ssl/api.example.com.pem;
    ssl_certificate_key /etc/nginx/ssl/api.example.com.key;
    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}

server {
    listen 443 ssl;
    server_name admin.example.com;

    ssl_certificate     /etc/nginx/ssl/admin.example.com.pem;
    ssl_certificate_key /etc/nginx/ssl/admin.example.com.key;
    root /var/www/gym-admin;
    index index.html;
    client_max_body_size 20m;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}

server {
    listen 80;
    server_name api.example.com admin.example.com;
    return 301 https://$host$request_uri;
}
```

`api` 这一段里的 `Upgrade` 三行是闸机 WebSocket 用的，不能删。

```bash
sudo nginx -t
sudo systemctl reload nginx
```

`nginx -t` 必须显示 `syntax is ok` 再 reload。

## 5. 打包并启动后端

本机：

```powershell
cd D:\AIProject\健身房小程序\code\server
D:\AIProject\健身房小程序\.tools\apache-maven-3.9.9\bin\mvn.cmd -DskipTests package
scp "D:\AIProject\健身房小程序\code\server\target\gym-server-0.1.0.jar" root@公网IP:/opt/gym/gym-server.jar
```

服务器上新建 `/etc/systemd/system/gym-server.service`：

```ini
[Unit]
Description=gym-server
After=network.target mysql.service redis-server.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/gym
EnvironmentFile=/etc/gym/gym-server.env
ExecStart=/usr/bin/java -jar /opt/gym/gym-server.jar
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

`ExecStart` 里的 java 路径以 `which java` 为准。

```bash
sudo systemctl daemon-reload
sudo systemctl enable gym-server
sudo systemctl start gym-server
sudo systemctl status gym-server
curl -sS http://127.0.0.1:8080/api/health
```

`status` 应是 `active (running)`。失败时看 `sudo journalctl -u gym-server -n 100 --no-pager`。

浏览器打开 `https://api.example.com/api/health`，应同样返回 `code` 为 0。502 表示 Java 没起来。

以后只更新后端：重新打包，scp 覆盖同一个 `gym-server.jar`，再 `sudo systemctl restart gym-server`。

## 6. 管理端

构建前在 `code/admin/.env.production` 写高德 Key（不要提交 Git）：

```env
VITE_AMAP_KEY=你的Key
VITE_AMAP_SECURITY_JS_CODE=你的安全密钥
```

本机：

```powershell
cd D:\AIProject\健身房小程序\code\admin
npm install
npm run build
scp -r "D:\AIProject\健身房小程序\code\admin\dist\*" root@公网IP:/tmp/gym-admin-dist/
```

服务器上：

```bash
sudo mkdir -p /var/www/gym-admin
sudo rm -rf /var/www/gym-admin/*
sudo cp -r /tmp/gym-admin-dist/* /var/www/gym-admin/
```

目录里应有 `index.html`。浏览器打开 `https://admin.example.com`。初始总账号是 `admin` / `admin123`，登录后立刻改掉。

管理端不用改接口地址。页面能开但登录失败：检查上面 `location /api/`。以后只更新页面时重新 build、覆盖文件，不用重启 Java。

高德控制台把 `admin.example.com` 加进这个 Key 的白名单，否则地图选点失败。改 Key 必须重新 build。

## 7. 微信小程序和支付

微信公众平台 → 开发管理 → 开发设置：

| 项 | 填什么 |
| --- | --- |
| request、uploadFile、downloadFile | `https://api.example.com` |
| socket 合法域名 | `wss://api.example.com` |

公开图也在这个域名的 `/uploads/`，不用另配对象存储域名。

改源码后再打包：

1. `code/mp/src/api/http.ts` 和 `code/mp/src/api/auth.ts` 的非 H5 地址都改成 `https://api.example.com`，不要末尾斜杠，不要带端口。
2. `manifest.json` 的 `mp-weixin.appid` 填这个小程序的 AppID。根上的 `appid` 是 DCloud 用的，不要填成微信 AppID。

```powershell
cd D:\AIProject\健身房小程序\code\mp
npm install
npm run build:mp-weixin
```

用微信开发者工具导入 `code\mp\dist\build\mp-weixin`。上传前不要勾选「不校验合法域名」。上传后在公众平台提交审核再发布。

小程序代码不上传到服务器。支付回调地址就是环境变量里的 `https://api.example.com/api/mp/pay/notify`，不用在微信后台另填一个路径。商户平台要把这个小程序 AppID 关联到商户号。

用户隐私保护指引里声明手机号、位置、摄像头。服务类目选和健身场馆相符的项。

## 8. 闸机

1. `https://api.example.com/api/health` 已经能打开。
2. 管理端 → 闸机：新增设备，SN 与闸机屏幕上的设备号完全一致，选对门店，需要进出两台时分别设方向。
3. 闸机屏按 [闸机屏端配置](闸机屏端配置.md) 的「正式域名」填写。长连接路径固定 `/ws/gate`，走 `wss`，端口 443。
4. 管理端约 3 分钟内显示在线后，再测注册、购卡、认脸开门。

购卡或后台开卡之后，人脸才会下发到闸机。教练和进门管理员按各自的到期时间下发，不出现在会员列表。

## 9. 上线前检查

- 总账号已改掉 `admin` / `admin123`。
- `JWT_ADMIN_SECRET`、`JWT_MP_SECRET` 不是仓库里的默认串。
- `WX_MP_SECRET` 是 32 位，和 AppID 是一对。
- 安全组没有放行 8080、3306、6379。
- 删掉清空数据暗门。管理端右上角「总账号」按住约 0.8 秒会清空全部业务数据，并向在线闸机删除人员。正式环境不能留。删这三处：
  - `code/admin/src/layouts/AdminLayout.vue` 里按住「总账号」的计时和确认框
  - `DataWipeController`、`DataWipeService`
  - `GateFaceSync.removeEveryone`
- 会员卡和课时不能退款。参观押金按时离店或未进店可以退，这是单独通路。

开机自启：

```bash
sudo systemctl is-enabled gym-server mysql redis-server nginx
```

四行都应是 `enabled`。

### 1.6 公网 IP 的站点

Ubuntu 自带站点也占用 80 端口。先删掉它，再写入下面这份。管理端上传的图片地址是 `http://公网IP/api/uploads/...`，走下面的 `location /api/`。`location /uploads/` 留着，旧地址也能打开。

```bash
sudo rm -f /etc/nginx/sites-enabled/default
sudo tee /etc/nginx/conf.d/gym.conf >/dev/null <<'EOF'
server {
    listen 80 default_server;
    server_name _;
    root /var/www/gym-admin;
    index index.html;
    client_max_body_size 20m;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }

    location /h5/ {
        alias /var/www/gym-h5/;
        index index.html;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
EOF
sudo nginx -t
sudo systemctl reload nginx
```

`nginx -t` 必须显示 `syntax is ok`。管理端页面还没上传时，浏览器打开公网 IP 会是空目录或 404。上传在 2.4，域名下来之前也可以先做那一节的上传命令。H5 打包上传见下一节，地址是 `http://公网IP/h5/`。

## 2. 域名审核通过后再做

`xz100w.com` 能做解析之后按这个顺序。网站备案若还没过，外网用浏览器打开域名可能被拦截；解析、证书、Nginx 仍可以先配，本机 health 已经在上一节测过。

### 2.1 解析

阿里云云解析给 `xz100w.com` 加两条 A 记录，记录值都是这台 ECS 的公网 IP。


| 主机记录    | 类型  | 结果                 |
| ------- | --- | ------------------ |
| `api`   | A   | `api.xz100w.com`   |
| `admin` | A   | `admin.xz100w.com` |


本机：

```powershell
nslookup api.xz100w.com
nslookup admin.xz100w.com
```

返回的地址应等于公网 IP。

### 2.2 证书

在阿里云 SSL 申请证书，绑定 `api.xz100w.com` 和 `admin.xz100w.com`，或一张 `*.xz100w.com`。下载 Nginx 格式。

服务器上：

```bash
sudo mkdir -p /etc/nginx/ssl
sudo chmod 700 /etc/nginx/ssl
```

本机上传（文件名按实际下载的改）：

```powershell
scp "C:\Users\你的用户名\Downloads\证书目录\xxx.pem" root@公网IP:/etc/nginx/ssl/api.xz100w.com.pem
scp "C:\Users\你的用户名\Downloads\证书目录\xxx.key" root@公网IP:/etc/nginx/ssl/api.xz100w.com.key
```

管理端若是另一张证书，再传：

- `/etc/nginx/ssl/admin.xz100w.com.pem`
- `/etc/nginx/ssl/admin.xz100w.com.key`

通配符证书则两个站点共用 `api` 那一套文件，Nginx 里两处都写这个路径。

### 2.3 Nginx

两张独立证书时用下面这份。通配符证书把 admin 的两行 ssl 路径改成和 api 相同。`api` 的 `location /` 已包含 `/uploads/`。`admin` 上单独写了 `/uploads/`，避免图片打开成管理端页面。

```bash
sudo tee /etc/nginx/conf.d/gym.conf >/dev/null <<'EOF'
server {
    listen 443 ssl;
    server_name api.xz100w.com;

    ssl_certificate     /etc/nginx/ssl/api.xz100w.com.pem;
    ssl_certificate_key /etc/nginx/ssl/api.xz100w.com.key;
    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}

server {
    listen 443 ssl;
    server_name admin.xz100w.com;

    ssl_certificate     /etc/nginx/ssl/admin.xz100w.com.pem;
    ssl_certificate_key /etc/nginx/ssl/admin.xz100w.com.key;
    root /var/www/gym-admin;
    index index.html;
    client_max_body_size 20m;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }

    location /h5/ {
        alias /var/www/gym-h5/;
        index index.html;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}

server {
    listen 80;
    server_name api.xz100w.com admin.xz100w.com;
    return 301 https://$host$request_uri;
}
EOF
sudo nginx -t
sudo systemctl reload nginx
```

`nginx -t` 必须是 `syntax is ok`。然后浏览器打开 `https://api.xz100w.com/api/health`。

### 2.6 备案通过后再交给微信和闸机

小程序正式版要求域名已做网站备案。备案没过时，不要把这个域名填进小程序的服务器域名。

备案通过、并且 `https://api.xz100w.com/api/health` 外网能打开之后：

1. 小程序后台的 request、uploadFile、downloadFile 填 `https://api.xz100w.com`，socket 填 `wss://api.xz100w.com`。图片也走这个域名下的 `/uploads/`。
2. 小程序代码里的接口地址改成 `https://api.xz100w.com`，去掉本机测试地址后再上传审核。
3. 支付回调保持 env 里的 `https://api.xz100w.com/api/mp/pay/notify`，用一笔真实支付确认能回调。
4. 闸机服务器地址填 `https://api.xz100w.com`，长连接填 `wss://api.xz100w.com/ws/gate`。然后在管理端登记设备号。

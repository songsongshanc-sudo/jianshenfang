# 教练续课率 + 提前续约优惠 — 需求理解

> 2026-10-22 按最新口径整理，并已按此实现。  
> 续课率规则不变。会员卡和课程不做自动续费，也不申请微信支付委托代扣。符合条件时，用户自己再付一笔，按提前续约优惠价成交。没配优惠价就不出现这个入口。

---

## 1. 一句话

1. 管理端统计每位教练的续课率：同一学员把这个教练的课上完后，再买这个教练的课，算续课成功。不限间隔天数。后台开的课也算。
2. 会员卡还没到期、或这门课还有剩余课时时，再买同一张卡或同一个课包，可以按管理端配的优惠价付一次。到期或课时用完之后再买，按原价。不会自动扣下一期。

---

## 2. 和现状的关系

| 已有 | 本期要加 |
| --- | --- |
| 课包挂在教练下。同一学员、同一课包只有一条剩余课时 | 按每一笔购课订单的节数判断这包有没有上完，再看之后有没有再买同一教练 |
| 扣课：教练同意预约扣 1 节，或扫课时码扣 1 节。退课把这 1 节加回 | 退回后剩余又大于 0，这包还没上完，此时再买可走提前续约价 |
| 会员卡按天数写到期时间，再买一张再开一段 | 未到期再买同一张卡时用优惠价，天数接在这张卡当前最晚到期日之后 |
| 课程详情只有「立即购买」 | 还没上完且配了优惠价时，按钮改为「提前续约」，价格用优惠价 |
| 支付是单笔预下单 | 提前续约仍走这一笔支付，用户点一次、付一次 |
| 购买后不能退款、不能停卡、不能改门店 | 提前续约成交后同样不退、不停、不改门店 |

参观卡不做提前续约。现有财务统计不包含续课率。

续课率和提前续约是两件事。课时用完后再买，续课率算成功，价格按原价。课时还没用完就再买，走提前续约优惠，这一笔不算「上完」，也不算续课成功。

---

## 3. 教练续课统计

统计单位是「一位学员 + 一位教练 + 一笔买断的课时」。不按节、不按金额。

| 名词 | 规则 |
| --- | --- |
| 上完 | 这一笔订单带来的节数已被扣光。预约同意和扫码核销都算扣课。退课加回后剩余又大于 0，则还没上完 |
| 续课成功 | 上完之后，该学员再次得到**同一个教练**名下的课。可以是另一门课包。不限隔了多久 |
| 算购买 | 小程序支付、以及管理端给学员开的课，都算。后台再开一包，也会记进续课成功 |
| 续课率 | 筛选范围内已上完的笔数里，后来续课成功的笔数占比 |

同一学员对同一教练有多笔课时时，每笔上完各算一次。续课成功只挂在「上完之后、下一次买课之前」的那一笔上，一笔新购课不能把更早的每一笔都算成成功。

不算的情况：

- 课时还没用完就又买了，这是加课，不算续课，这一笔也不进「上完」。
- 只预约、教练还没同意、没扣课，不算上过。
- 没有对应购课或后台开课订单、只是改了剩余节数的，不单算一笔。

同一课包重复购买会加在同一条剩余课时上。统计必须以每一笔订单的节数为界，不能只看当前剩余是不是 0。

管理端：

- 放在教练管理里。门店账号只看本店教练，总账号可看全部并按门店筛选。
- 列：教练、门店、上完笔数、续课成功笔数、续课率。可按上完时间筛选。
- 点开教练可看名单：学员、课包、上完时间、是否已续、续课时间和课包名。

## 4. 提前续约优惠

用户自己再买一次。系统不到期扣款，也不发「待支付」提醒。

### 4.1 什么时候用优惠价

每一张会员卡、每一个课包单独配置：打开开关，并填写大于 0 的提前续约价。没打开或没填价格的，只有现在的原价购买。

优惠价可以等于原价，系统不强制必须更便宜。

| 商品 | 用优惠价 | 用原价 |
| --- | --- | --- |
| 会员卡 | 这张卡在该会员身上还未到期 | 从未买过，或已经过了到期时间 |
| 课程课包 | 这个课包还有剩余课时 | 从未买过，或剩余课时已经是 0 |

「这张卡」指同一个卡种。「这个课包」指同一个课包。买另一张卡、另一门课，不借用这一张的优惠价。

会员卡的天数接在该卡当前最晚到期日之后，不从付款当天重算。课程的节数加进这个课包的剩余课时。跨店规则与现在购买相同，不能借续约改门店。

会员卡若设了库存，这一笔库存不足就下单失败，和普通购买一样。

### 4.2 页面上怎么出现

符合 4.1 的优惠条件时，只显示一个「提前续约」按钮，价格是提前续约价。不符合时，只显示原来的「立即购买」，价格是原价。不同时放两个都能付款的按钮。

确认页写明：本次是未到期续约，按优惠价付一次，付完后不自动扣下一期。下单前仍须同意现有会员协议。协议正文不用写自动扣款。

### 4.3 改价和关掉开关

- 关掉开关或清空价格：之后的新下单不再走优惠，按钮回到「立即购买」。已经付完的那一期不变。
- 改提前续约价：只影响之后新下的单。已经付完的那一期仍是当时的成交价。

### 4.4 不做的事

- 不做自动续费，不签约，不按周期扣下一期。
- 不申请微信支付委托代扣，不为每张卡准备微信模板编号。
- 不做「关闭自动续费」。想再续就再点一次提前续约并付款。
- 不把已付的这一期退款、停卡或改门店。

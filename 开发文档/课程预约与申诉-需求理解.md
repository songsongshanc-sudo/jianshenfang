# 课程预约 / 选座 / 申诉 — 需求理解

> 需求已对齐（含漏洞补丁与管理端消息审计），**已按本文实现**（V10 + 管理端消息审计 + 小程序预约/教练处理/未读跳转）。  
> 对照：课包教室/排班、预约审批双轨扣课、`message_audit` 门店·教练筛选、小程序未读红点与详情跳转。

---

## 1. 一句话

学员在已购课包上**提前预约上课**：选日期、排班时段、座位；教练**同意后扣 1 节**；未同意前可随时取消；临近上课不可随意取消；可申诉，教练退课则加回课时。也可不预约、用**课时二维码**临时扣课。所有关键节点写入站内消息；**小程序与管理端都能看到**，管理端可按**门店 / 教练**筛选，作为纠纷证据。

## 2. 与现状的关系

| 已有 | 本期要加 |
| --- | --- |
| 管理端创建课程（课包） | 课包**教室长宽**（不再做教练排班；学员自选开始时间） |
| 「我的课程」+ 课时二维码 | **预约**入口；二维码保留给临时上课 |
| 教练扫码核销 | 教练端预约/申诉：同意、拒绝、退课、驳回；可电话沟通 |
| 站内信（用户维度）+ 管理端「发给指定用户」 | 业务自动发信；小程序未读红点与跳转；**管理端消息列表可查、可按门店/教练筛选** |

### 双轨扣课

- 预约成功（教练同意）→ 立即扣 1 节，不必再扫码。  
- 未预约临时上课 → 出示二维码，教练扫码扣 1 节。  
- 两条路并存。

## 3. 规则（已定 + 漏洞补丁已采纳）

### 3.1 教室与选座

- 课包设置 **宽（列）× 长（行）**，范围 **1～20**，默认建议 5×5；学员座 = 宽×长。  
- **教练位在网格外**，不占学员格。座位编号 `行-列`（如 `1-1`）。  
- 选座：可选 / 已占用（含待同意锁定）/ 格外教练区。  
- **提交即锁座**；同一课包 + 上课日 + 排班时段内座位互斥。  
- **同堂可多人**（按座位数）。  
- 缩小教室后：已占用座位保留到该预约结束，**新预约**按新尺寸。

### 3.2 上课时间（无管理端排班）

- **不做**管理端教练排班；双方可用电话沟通细节。  
- 学员预约时自选开始时刻（半小时一档，约 06:00～22:00）。  
- 结束 = 开始 + **该课包单节分钟**。  
- 课包下架：禁止新预约；进行中的待同意/已确认仍走完。

### 3.3 日期与冲突

| 项 | 规则 |
| --- | --- |
| 最早 | 至少提前 1 个自然日（时区上海） |
| 最远 | 明天起共 **7** 天内 |
| 同学员同时段 | 禁止与其他课**时间重叠**的预约 |
| 同课同堂 | 同一学员同一课包+日+时段仅 **1** 条有效预约（待同意或已确认） |
| 待同意数量 | 同一学员对同一课包最多 **1** 条 `PENDING_COACH` |
| 提交前 | 须 `remaining ≥ 1` |

### 3.4 预约与课时

| 节点 | 规则 |
| --- | --- |
| 提交 | `PENDING_COACH`；锁座；不扣课 |
| 待同意截止 | **`min(提交+48h, 上课开始时间)`**；到期未处理 → 自动取消、释座、发消息 |
| 待同意取消 | 学员随时可取消 → 释座、不扣课、发消息 |
| 教练同意 | 须 **未到开课时间** 且 **remaining ≥ 1** → `CONFIRMED`，扣 1 节；否则同意失败：若已过开课或课时不足 → **自动取消并释座**，通知双方 |
| 教练拒绝 | **必须填原因** → `REJECTED`；释座；通知学员 |
| 已确认取消 | 距开课 **≥24h**：可取消，**退 1 节**，释座，发消息；**&lt;24h** 不能取消 |
| 申诉 | 仅 `CONFIRMED` 可发起；**随时可申**；不限历史次数；存在未结束 `APPEALING` 时**不能并行再提**（驳回后可再提） |
| 退课 | 教练确认（过开课时间须二次确认文案）→ 课时 +1，释座；**同一预约只退成功一次**；→ `REFUNDED` 终态，不可再申诉/再退 |
| 驳回申诉 | **须填原因**；回到可再申诉的 `CONFIRMED`；通知学员 |
| 防作弊 | 本期无签到；依赖教练电话沟通 + 退课确认；详情过开课时间要醒目标注 |

### 3.5 详情与电话

详情含：学员名、会员号（`member_no`）、手机号、日期、时间、座位、课程名、状态；申诉另含申诉时间、原因、历史。

- **仅该课教练**可见并一键拨打学员手机。  
- 学员端不展示「拨打自己」。

### 3.6 教练端

列表：学员名、头像、课程名、座位、状态。  
操作：同意 / 拒绝（原因）/ 退课 / 驳回申诉（原因）。点进详情（含电话）。

## 4. 消息（小程序 + 管理端审计）

### 4.1 必须落库的事件（双方或单方站内信 + **管理端可查副本**）

| 事件 | 学员 | 教练 | 管理端审计 |
| --- | --- | --- | --- |
| 发起预约 | — | ✓ | ✓ |
| 预约成功 | ✓ | — | ✓ |
| 拒绝（含原因） | ✓ | — | ✓ |
| 学员取消（待同意/已确认） | ✓ | ✓ | ✓ |
| 超时/过开课/课时不足导致取消 | ✓ | ✓ | ✓ |
| 发起申诉 | — | ✓ | ✓ |
| 退课成功 | ✓ | — | ✓ |
| 申诉驳回（含原因） | ✓ | — | ✓ |

说明：每条业务消息除推送给用户外，须在管理端**可检索**（见 4.3）。避免日后纠纷无证据。教练未绑定小程序用户时：跳过教练站内信，**仍写管理端审计记录**并打日志。

### 4.2 小程序

- 消息列表 + 未读红点；「我的」入口红点。  
- 点 Item → 预约/申诉详情并已读。  
- 教练消息发到绑定教练手机号的登录用户。

### 4.3 管理端消息（本期强化）

现状只有「填写用户编号发一条」。本期改为：

1. **列表展示全部业务消息/审计记录**（含系统自动产生的预约相关消息），不只手发。  
2. **筛选**：  
   - 按**门店**（总账号可选全部门店；门店账号默认本店）  
   - 按**教练**（本店教练列表）  
   - 建议再支持：消息类型（预约/取消/申诉/退课/拒绝等）、时间范围、学员关键词（手机/会员号）  
3. 列表字段至少：时间、门店、教练、学员（名/会员号/手机）、类型、标题/摘要、关联预约 ID、是否已读（用户侧）。  
4. 点击可看详情摘要（原因文案、座位、上课时间等），便于客服取证。  
5. 保留原「手动发给指定用户」能力（运营通知）。  
6. **管理端可对预约/申诉执行操作**（同意、拒绝、退课、驳回申诉），与教练端规则相同；详情须标注**操作端：教练 / 门店**。业务消息本身不可删改。

实现提示：可在 `inbox_message` 扩展 `biz_type` / `biz_id` / `store_id` / `coach_id`，或另建 `message_audit` 与用户收件箱双写；以「管理端必能按门店·教练筛出全程」为准。

## 5. 学员主路径

```
我的课程 → 预约 → 日历(明天起7天) → 排班开始时刻 → 选座 → 提交(锁座,须有课时)
  ├─ 取消 / 到 min(48h,开课) 未处理 / 同意时过期或无课时 → 释座 + 消息(含管理端)
  ├─ 教练拒绝(原因) → 释座 + 消息
  └─ 教练同意 → 扣 1 课时
        ├─ ≥24h 取消 → 退 1 课时 + 消息
        ├─ &lt;24h 不可取消
        └─ 申诉(有进行中则不可并行) → 退课(+1,仅一次) 或 驳回(可再申诉)
```

临时上课：二维码 → 教练扫码扣 1 节。

---

## 6. 状态机

```
PENDING_COACH  锁座未扣课；截止 min(提交+48h,开课)；可取消/同意/拒绝
CONFIRMED      已扣 1 课；≥24h 可取消退课；可申诉
REJECTED       拒绝（有原因）
CANCELLED      学员或系统取消
APPEALING      申诉中（同时仅一条）
REFUNDED       已退课终态；不可再申诉/再退
```

驳回申诉 → 回到 `CONFIRMED`，可再次申诉。

## 7. 本期范围

**做：**

1. 课包教室长宽（1～20）；选座（教练区格外）。  
2. 学员自选开始时间（半小时档）；管理端不配排班。  
3. 预约全流程与漏洞补丁（截止时间、同意校验、锁座限制、退课一次等）。  
4. 保留二维码核销。  
5. 小程序消息增强。  
6. **管理端消息审计列表 + 门店/教练等筛选（只读业务消息）**。  
7. 教练端列表与详情（含拨打电话）。

**不做：** 订阅消息/短信；签到；多教室资源池；跨店约课；超过 3 个排班。

---

## 8. 验收场景

1. 5×5 选座 + 格外教练区；学员自选开始时间。  
2. 可约明天起 7 天；提交须有课时并锁座。  
3. 待同意截止为 min(48h, 开课)；过开课或课时不足无法同意并自动取消。  
4. 同意扣课；拒绝/驳回须原因；≥24h 取消退课；&lt;24h 不可取消。  
5. 申诉不并行、历史不限次；退课仅一次；`REFUNDED` 不可再申。  
6. 二维码临时扣课仍可用。  
7. 小程序未读红点；详情可拨学员电话。  
8. **管理端能按门店、教练筛出预约/取消/申诉/退课等全程消息，内容可作纠纷证据。**

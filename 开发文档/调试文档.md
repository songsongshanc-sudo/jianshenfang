# 调试文档

本地调试用这份。线上要配的密钥、域名和闸机，见 `开发文档/发布文档.md`。

当前这台电脑不能装 Docker，后端用 `local`。能装 Docker 的电脑用 `dev`。两套都走测试数据，不需要微信、对象存储、人脸云的密钥。正式环境必须是 `prod`，步骤在技术设计第 5.1 节。

## 1. 本地哪些功能是测试数据

`local`、`dev` 和单元测试走下面这些测试实现。页面没有另写一条“假装成功”的分支，接口和正式环境相同。`prod` 不会使用这些数据。

| 功能 | 本地实际发生的事 | 测试数据在哪 |
| --- | --- | --- |
| 手机号登录 | 登录页「本机测试」填 `1` 开头的 11 位数字，这个数字就是手机号。不向微信换号 | `local` / `dev` / `test` 的 `LocalWxAuth` |
| `wx.login` | code 换成测试 openid，只供以后支付使用，这一步不算登录成功 | 同上 |
| 支付 | 点「模拟支付成功」。购卡会写入会员，购课只加课时。钱不是微信支付 | `application-local.yml`、`application-dev.yml` 里 `gym.pay.mock-enabled: true` |
| 人脸照片 | 必须传一张图，小于 32 字节会要求重拍。服务端不判断是不是人脸。照片存在 `code/server/data/private/face`，管理端不展示 | 本机磁盘。会员编号仍会签发 |
| 闸机 | 没有实机时，管理端「模拟验码」用设备密钥做 HMAC，走同一套开门判断。购卡后的下发任务会排队，闸机连上 `ws://能访问到的地址/ws/gate` 才会真正推送 | 模拟验码不需要厂商设备。`127.0.0.1` 闸机访问不到 |
| 图片上传 | Banner、封面、到店指引写到 `code/server/data/public`，返回 `http://127.0.0.1:8080/uploads/...` | 本机磁盘，不是对象存储 |
| 内容安全 | 报修、投诉、失物文字里包含「违禁」会拒绝，其他文字通过 | 不调微信 `msgSecCheck` |
| 地图选点 | 管理端用高德 JS 地图，坐标 GCJ-02。这是真实地图，Key 在 `code/admin/.env.local` | 仓库里的 Key。没配时地图打不开，可以手填经纬度 |
| 团购 | 总账号先录入券码和卡种，会员提交后立即核销。券码只存 SHA-256 | 不调美团、抖音 |
| 好评赠卡 | 美团、抖音都是空列表，不会发会员 | 占位 |
| 学生认证 | 只有「未认证」，不改卡价 | 占位 |
| 登录态 | `local` 和单元测试放内存，重启后端后管理端和小程序都要重新登录。`dev` 放 Redis，重启后端登录还在 | `local` 不连 Redis |
| 数据库 | `local` 和单元测试用 H2，文件在 `code/server/data`。`dev` 用 Docker 里的 MySQL，库 `gym`，用户 `gym`，密码 `gym_dev` | H2 里的门店和卡种不会自动进 MySQL |
| 总账号 | 种子账号 `admin` / `admin123` | 上线前要改掉，见发布文档 |
| 课时码 | 出示后 60 秒内有效，存在本机内存。教练手机号必须等于当前登录会员的手机号 | `local` 重启后码失效。闸机遇到 `lesson:` 不开门 |
| 在线人数 | 默认按 90 分钟统计该店成功进店的去重人数 | 规则是正式的，数据来自本机进店记录 |

防重放和 15 秒开门防抖：`local` 放内存，重启会清空；`dev` 放 Redis。

## 2. 本机启动（没有 Docker）

PowerShell 不支持 `&&`，命令一条一条执行。带逗号的 Maven 参数要加引号。

```powershell
cd code\admin
npm install
npm run dev
```

管理端是 `http://localhost:5173`，接口代理到 `http://127.0.0.1:8080`。总账号 `admin` / `admin123`。

另开一个终端：

```powershell
cd code\mp
npm install
npm run build:mp-weixin
```

微信开发者工具导入 `code\mp\dist\build\mp-weixin`。打开「详情 → 本地设置」，勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`manifest.json` 的 `appid` 是空的，导入时可选测试号或游客模式。登录页用「本机测试」填 11 位手机号。改了小程序源码后要重新执行 `npm run build:mp-weixin`，再在开发者工具里重新编译。

再开一个终端，工作目录必须是 `code\server`，H2 写在这个目录下的 `data`：

```powershell
cd code\server
mvn spring-boot:run "-Dspring-boot.run.profiles=local"
```

看到 `Started GymApplication` 后，接口在 `http://127.0.0.1:8080`。

注意：

- 8080 上只能有一个后端。
- 小程序请求地址写死为 `http://127.0.0.1:8080`。
- `local` 的登录令牌在内存里，重启后端后要重新登录。

## 3. 用 Docker 的电脑（`dev`）

管理端和小程序的安装、编译与第 2 节相同。后端改成：

```powershell
cd code
docker compose up -d
cd code\server
mvn spring-boot:run
```

Compose 启动 MySQL 8（3306，库 `gym`，用户 `gym`，密码 `gym_dev`）和 Redis 7（6379，无密码），时区 `Asia/Shanghai`。不加 `profiles=local` 时，默认 profile 是 `dev`。空库只有总账号、空协议和几项系统配置。

`dev` 的手机号、支付、图片、内容安全仍是第 1 节的测试数据。登录态放 Redis，重启后端不用重新登录。

这台电脑 `code/server/data` 里的 H2 门店和卡种不会自动进 MySQL。要接着用旧数据时，停掉后端，把整个 `data` 复制到新电脑同一位置，再用第 2 节的 `local` 命令启动。复制时后端不能开着。

## 4. 换电脑时不要拷的目录

| 目录 | 原因 |
| --- | --- |
| `code/admin/node_modules`、`code/mp/node_modules` | 新电脑各自 `npm install`。`package-lock.json` 留在仓库里 |
| `code/server/target` | Maven 编译结果 |
| `code/mp/dist`、`code/admin/dist` | 到新电脑后重新编译 |
| `.tools` | 临时 Maven，不进仓库 |
| `code/server/data` | 仅 `local` 的 H2 和上传文件。要接着用旧数据时单独拷，不要提交 |

`.gitignore` 已包含这些路径。版本对齐：JDK 17、Maven 3.9.9、Node.js 22。不能装 Docker 时跳过 Docker，后端用第 2 节。Windows 上 Docker Desktop 需要先有 WSL2。

`local` 和 `dev` 不用另设数据库、Redis、登录密钥、微信和对象存储变量。配了也不会拿去调正式接口。

端口：`3306` MySQL，`6379` Redis，`8080` 后端，`5173` 管理端。
